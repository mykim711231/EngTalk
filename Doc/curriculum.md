# EngSpeak 12권 240과 편성안

각 표는 같은 과 번호에서 세 권의 주제를 나란히 보여줍니다. 원고가 작성된 과는 제목을 눌러 열 수 있습니다.

## 권별 말하기 목표와 문법

문법 ID와 예문은 [문법 목차](Grammar/README.md)에서 확인합니다. 앞에서 배운 문장 구조는 뒤쪽 권에서 새로운 상황에 다시 사용합니다.

| 권 | 권을 마치면 할 수 있는 말 | 중심 문법 |
|---|---|---|
| 1권 첫 일상회화 | 이름과 하는 일을 소개하고, 음료를 주문하고, 약속 시간을 정합니다. | G01 문장 뼈대, G02 be동사, G03 기본 의문문, G04 정중한 요청 |
| 2권 외식·쇼핑 | 옵션과 가격을 묻고, 결제하거나 교환을 요청합니다. | G04 요청, G05 관사·수량·가격 |
| 3권 이동·동네 생활 | 목적지를 말하고, 길을 묻고, 안내를 확인합니다. | G03 질문, G06 위치·방향과 명령문 |
| 4권 해외여행 | 예약 내용을 확인하고, 놓친 항공편을 설명하고, 대체 일정을 정합니다. | G07 과거, G08 미래, G09 조건 |
| 5권 생활 정착과 서비스 | 집과 서비스의 조건을 확인하고, 문제가 언제 어떻게 발생했는지 설명합니다. | G07 과거, G09 이유와 조건, G11 간접 질문 |
| 6권 관계와 사회생활 | 상대를 초대하거나 정중히 거절하고, 이유를 말하고 대안을 제안합니다. | G04 정중한 요청, G08 계획, G09 이유 |
| 7권 직장 기본 | 담당 업무를 소개하고, 해야 할 일과 마감일을 다시 확인합니다. | G01 문장 뼈대 복습, G10 진행과 완료, G11 간접 질문 |
| 8권 회의·보고·발표 | 진행 상황과 지연 이유를 알리고, 담당자와 다음 행동을 요약합니다. | G10 진행과 결과, G12 상태와 처리 결과, G17 근거와 결론 |
| 9권 고객·협상·프로젝트 | 고객의 요구를 확인하고, 일정이나 범위가 바뀔 때 가능한 조건을 협의합니다. | G11 확인 질문, G12 상태 변화, G13 조건과 합의 |
| 10권 자연스러운 구어체 | 놓친 말을 확인하고, 어색하게 꺼낸 말을 고치고, 같은 요청의 정중함을 조절합니다. | G02 축약형 복습, G04 요청 표현, G11 확인 질문 |
| 11권 토론·시사 | 다른 주장을 정확히 요약하고, 일부를 인정하면서 자신의 근거를 설명합니다. | G14 전달, G15 양보와 대조, G17 근거와 결론 |
| 12권 인터뷰·설득·발표 | 후속 질문을 하고, 대안의 결과를 설명하고, 청중에게 다음 행동을 제안합니다. | G11 간접 질문, G16 가정과 대안, G17 결론 |

# 09. 프로젝트 상태를 짧게 보고하기 (Giving a Short Project Status Update)

## 학습 목표

- 과 ID · vol8-09
- 핵심 문법 · G10 진행·완료·결과로 주간 상태 보고하기
- 상황 검색어 · 주간 업데이트, 완료된 일, 진행 중인 일, 막힌 일, 도움 요청
- 말하기 목표 · 끝난 일, 진행 중인 일, 막힌 일, 다음 단계를 짧게 나누어 보고하고 필요한 도움을 구체적으로 요청합니다.

## 기본 대화

A는 프로젝트 리드 Maya이고 B는 매니저 Daniel입니다. Maya가 결제 화면 재설계의 주간 상태를 완료, 진행 중, 막힌 일, 다음 단계 순서로 짧게 보고합니다.

- **A** Quick weekly update. / The checkout redesign is on track.
  - 짧게 주간 업데이트하겠습니다. 결제 화면 재설계는 예정대로 진행 중입니다.
- **B** Good. / What's done so far?
  - 좋습니다. 지금까지 뭐가 끝났나요?
- **A** We've finished the design, / and the new payment page is live.
  - 디자인은 끝났고, 새 결제 페이지는 공개됐습니다.
- **B** Nice. / What's in progress?
  - 좋네요. 진행 중인 건 무엇인가요?
- **A** We're testing the refund flow now. / It's about seventy percent complete.
  - 지금 환불 절차를 테스트하고 있습니다. 약 70퍼센트 완료됐어요.
- **B** Any blockers?
  - 막힌 부분이 있나요?
- **A** One thing. / The refund API is still waiting for security approval, / so testing can't move to production yet. / Next, we'll finish the test plan. / Could you help me get the approval moved up?
  - 하나 있습니다. 환불 API가 아직 보안 승인을 기다리고 있어서 테스트를 실제 운영 환경으로 옮길 수 없습니다. 다음으로 테스트 계획을 마무리하겠습니다. 승인을 앞당길 수 있게 도와주시겠어요?
- **B** Yes. / I'll raise it with security today. / Thanks for the clear update.
  - 네. 오늘 보안 팀에 이야기할게요. 명확하게 업데이트해 줘서 고마워요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · We've finished the design, and the new payment page is live.
- 문장 구조 · `We`(주어) + `'ve finished`(현재완료) + `the design`(목적어) + `and` + `the new payment page`(주어) + `is live`(상태)
- 뜻과 어순 · G10에서 끝난 일의 결과는 `have/has + 과거분사`, 지금 하는 일은 `be + -ing`, 막힌 상태는 `be + 형용사/과거분사`로 말합니다. `We've finished`는 디자인이 끝나 결과가 남았다는 뜻이고, `is live`는 실제 공개된 상태, `are testing`은 진행 중, `is waiting`은 승인을 기다리는 상태입니다. 짧은 보고에서는 끝난 일, 진행 중인 일, 막힌 일을 한 문장씩 나눠 말하면 듣는 사람이 빠르게 파악합니다.
- 바꿔 말하기 · 완료 결과를 강조할 때는 `The design is done, and the page has been published.`라고 합니다. 진행 중이면 `We're testing the refund flow.`, 막혀 있으면 `We're blocked on security approval.`이라고 해 보세요.

## 주요 단어와 표현

주간 상태를 짧게 보고하고 필요한 도움을 요청할 때 쓰는 표현을 정리합니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### on track

- 발음 (미국식 IPA) · /ˌɑːn ˈtræk/
- 뜻 · 예정대로 진행되는
- 예문 · The checkout redesign is on track.
- 번역 · 결제 화면 재설계는 예정대로 진행 중입니다.

### weekly update

- 발음 (미국식 IPA) · /ˈwiː.kli ˈʌp.deɪt/
- 뜻 · 매주 하는 짧은 진행 보고
- 예문 · Quick weekly update.
- 번역 · 짧게 주간 업데이트하겠습니다.

### complete

- 발음 (미국식 IPA) · /kəmˈpliːt/
- 뜻 · 필요한 부분까지 다 된
- 예문 · It's about seventy percent complete.
- 번역 · 약 70퍼센트 완료됐습니다.

### live

- 발음 (미국식 IPA) · /laɪv/
- 뜻 · 실제 사용자에게 공개된
- 예문 · The new payment page is live.
- 번역 · 새 결제 페이지는 공개됐습니다.

### refund flow

- 발음 (미국식 IPA) · /ˈriː.fʌnd floʊ/
- 뜻 · 환불이 처리되는 절차
- 예문 · We're testing the refund flow now.
- 번역 · 지금 환불 절차를 테스트하고 있습니다.

### blocker

- 발음 (미국식 IPA) · /ˈblɑː.kɚ/
- 뜻 · 진행을 막는 문제
- 예문 · Any blockers?
- 번역 · 막힌 부분이 있나요?

### security approval

- 발음 (미국식 IPA) · /sɪˈkjʊr.ə.t̬i əˈpruː.vəl/
- 뜻 · 보안 팀의 승인
- 예문 · The refund API is still waiting for security approval.
- 번역 · 환불 API는 아직 보안 승인을 기다리고 있습니다.

### production

- 발음 (미국식 IPA) · /prəˈdʌk.ʃən/
- 뜻 · 실제 서비스가 운영되는 환경
- 예문 · Testing can't move to production yet.
- 번역 · 테스트를 아직 실제 운영 환경으로 옮길 수 없습니다.

### test plan

- 발음 (미국식 IPA) · /ˈtest plæn/
- 뜻 · 무엇을 어떻게 시험할지 정리한 계획
- 예문 · Next, we'll finish the test plan.
- 번역 · 다음으로 테스트 계획을 마무리하겠습니다.

### follow up

- 발음 (미국식 IPA) · /ˌfɑː.loʊ ˈʌp/
- 뜻 · 진행 상황을 다시 확인하다
- 예문 · We'll follow up with legal.
- 번역 · 법무 팀에 후속 확인을 하겠습니다.

### prioritize

- 발음 (미국식 IPA) · /praɪˈɔːr.ə.taɪz/
- 뜻 · 우선순위를 높여 먼저 처리하다
- 예문 · Could you ask them to prioritize it?
- 번역 · 우선 처리해 달라고 부탁해 주시겠어요?

### manager guide

- 발음 (미국식 IPA) · /ˈmæn.ɪ.dʒɚ ɡaɪd/
- 뜻 · 관리자용 안내서
- 예문 · The manager guide has been updated.
- 번역 · 관리자 안내서가 업데이트됐습니다.

### checklist

- 발음 (미국식 IPA) · /ˈtʃek.lɪst/
- 뜻 · 확인해야 할 항목을 정리한 목록
- 예문 · The new checklist is ready.
- 번역 · 새 체크리스트가 준비됐습니다.

## 발음 포인트

`We've finished the design, and the new payment page is live.`에서 `We've finished`는 `weev-FIN-isht`, `page is`는 `pay-ja-jiz`처럼 붙여 말합니다. `FIN-ished`와 `LIVE`를 또렷하게 강조해 끝난 일과 현재 상태를 분명히 하세요.

## 응용 대화

A는 HR 프로젝트 리드 Jisoo이고 B는 운영 책임자 Daniel입니다. Jisoo가 온보딩 개편의 주간 상태를 완료, 진행 중, 위험, 다음 단계 순서로 짧게 보고합니다.

- **A** Here's the weekly update on the onboarding project.
  - 온보딩 프로젝트 주간 업데이트입니다.
- **B** Thanks. / What's been completed?
  - 고마워요. 무엇이 완료됐나요?
- **A** The manager guide has been updated, / and the new checklist is ready.
  - 관리자 안내서가 업데이트됐고, 새 체크리스트가 준비됐습니다.
- **B** Good. / What's still in progress?
  - 좋아요. 아직 진행 중인 건 무엇인가요?
- **A** We're training the managers this week. / Two of four sessions are done.
  - 이번 주에 관리자 교육을 진행하고 있습니다. 네 번 중 두 번이 끝났어요.
- **B** Any risks?
  - 위험 요소가 있나요?
- **A** The legal review is taking longer than expected, / so the checklist can't be published yet. / Next, we'll follow up with legal. / Could you ask them to prioritize it?
  - 법무 검토가 예상보다 오래 걸려서 체크리스트를 아직 공개할 수 없습니다. 다음으로 법무 팀에 후속 확인을 하겠습니다. 우선 처리해 달라고 부탁해 주시겠어요?
- **B** Sure. / I'll contact legal today. / Thanks for keeping it short.
  - 물론입니다. 오늘 법무 팀에 연락할게요. 짧게 정리해 줘서 고마워요.

주간 보고는 길게 설명하기보다 `done`, `in progress`, `blocked`, `next` 순서로 네 문장 안에 정리하면 상대가 바로 도울 부분을 찾을 수 있습니다.

## 듣고 답하기

### 1. 완료와 진행 상황 보고하기

- 상대 음성 · Do you have a quick update on the checkout redesign?
- 힌트 · 디자인은 끝났고 결제 페이지는 공개됐으며, 환불 절차를 테스트 중이라고 말하세요.
- 예시 답변 · Yes. We've finished the design, and the new payment page is live. We're testing the refund flow now.
- 확인 · 끝난 일과 진행 중인 일을 구분했나요?

### 2. 막힌 일과 다음 단계 말하기

- 상대 음성 · Any blockers?
- 힌트 · 환불 API가 보안 승인을 기다리고 있어 운영 환경으로 넘어갈 수 없다고 말하고, 다음 단계를 설명하세요.
- 예시 답변 · One thing. The refund API is still waiting for security approval, so testing can't move to production yet. Next, we'll finish the test plan.
- 확인 · 막힌 원인과 다음 단계를 함께 말했나요?

### 3. 필요한 도움 요청하기

- 상대 음성 · Where do you need help?
- 힌트 · 보안 승인을 앞당길 수 있게 도와달라고 정중히 부탁하세요.
- 예시 답변 · Could you help me get the security approval moved up?
- 확인 · 필요한 도움을 구체적으로 요청했나요?

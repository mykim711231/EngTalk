# 13. 지연 사유와 새 일정 설명하기 (Explaining a Delay and a New Schedule)

## 학습 목표

- 과 ID · vol8-13
- 핵심 문법 · G10 진행·완료·결과로 지연과 새 일정 설명하기
- 상황 검색어 · 일정 지연, 변경된 API, 완료된 작업, 새 목표 날짜, 절충안
- 말하기 목표 · 지연 원인과 이미 끝난 일을 구분해 설명하고, 새 일정과 절충안을 제시하며, 날짜를 지키기 위해 필요한 결정을 요청합니다.

## 기본 대화

A는 프로젝트 리드 Maya이고 B는 고객 측 책임자 Daniel입니다. A가 공급업체 API 변경으로 생긴 지연을 설명하고, 새 목표 날짜와 절충안을 제시합니다.

- **A** I want to update you on the launch schedule. / We're going to miss the original date.
  - 출시 일정을 업데이트해 드리겠습니다. 원래 날짜를 맞추지 못하게 됐습니다.
- **B** Okay. / What caused the delay?
  - 알겠습니다. 지연 원인이 무엇인가요?
- **A** The vendor changed their API last week. / We've already updated the integration design, / but testing is taking longer than planned.
  - 지난주에 공급업체가 API를 바꿨습니다. 통합 설계는 이미 업데이트했지만, 테스트가 예상보다 오래 걸리고 있습니다.
- **B** How much longer do you need?
  - 얼마나 더 필요하신가요?
- **A** Two weeks. / The new target date is September 30.
  - 2주입니다. 새 목표 날짜는 9월 30일입니다.
- **B** What's the tradeoff if we keep the original date?
  - 원래 날짜를 지키면 어떤 절충이 필요하나요?
- **A** We'd have to leave out two reports from the first release. / If those reports are required, / we need the extra two weeks. / To hold September 30, / we need your approval by Friday.
  - 첫 출시에서 보고서 두 개를 빼야 합니다. 그 보고서가 반드시 필요하다면 2주가 더 필요합니다. 9월 30일을 지키려면 금요일까지 승인이 필요합니다.
- **B** Understood. / I'll confirm the priority by Thursday.
  - 알겠습니다. 목요일까지 우선순위를 확인하겠습니다.

## 문장 구조와 바꿔 말하기

- 대화 문장 · We've already updated the integration design.
- 문장 구조 · `We`(주어) + `'ve already updated`(현재완료) + `the integration design`(목적어)
- 뜻과 어순 · G10에서 이미 끝난 일은 `have/has already + 과거분사`, 지금 진행 중인 일은 `be + -ing`, 앞으로의 결과는 `be going to`로 말합니다. `We've already updated`는 설계 수정이 끝나 결과가 남았다는 뜻이고, `testing is taking longer`는 지금 지연이 이어지는 상태, `We're going to miss`는 앞으로 닥칠 결과를 미리 알리는 표현입니다. 지연을 설명할 때는 원인, 이미 한 일, 새 일정, 조건을 순서대로 말하면 신뢰를 유지하기 쉽습니다.
- 바꿔 말하기 · 이미 끝낸 일을 강조할 때는 `We've completed the design review.`라고 합니다. 지연이 이어지면 `The review is still taking longer than planned.`, 새 날짜를 말할 때는 `The new target date is October 7.`이라고 해 보세요.

## 주요 단어와 표현

지연 원인과 새 일정, 절충안을 설명할 때 쓰는 표현을 정리합니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### schedule

- 발음 (미국식 IPA) · /ˈskedʒ.uːl/
- 뜻 · 일을 언제 할지 정한 계획
- 예문 · I want to update you on the launch schedule.
- 번역 · 출시 일정을 업데이트해 드리겠습니다.

### miss a date

- 발음 (미국식 IPA) · /ˌmɪs ə ˈdeɪt/
- 뜻 · 정한 날짜를 지키지 못하다
- 예문 · We're going to miss the original date.
- 번역 · 원래 날짜를 맞추지 못하게 됐습니다.

### API

- 발음 (미국식 IPA) · /ˌeɪ piː ˈaɪ/
- 뜻 · 시스템끼리 데이터를 주고받는 연결 규칙
- 예문 · The vendor changed their API last week.
- 번역 · 지난주에 공급업체가 API를 바꿨습니다.

### integration design

- 발음 (미국식 IPA) · /ˌɪn.t̬əˈɡreɪ.ʃən dɪˈzaɪn/
- 뜻 · 두 시스템을 연결하는 설계
- 예문 · We've already updated the integration design.
- 번역 · 통합 설계는 이미 업데이트했습니다.

### tradeoff

- 발음 (미국식 IPA) · /ˈtreɪd.ɔːf/
- 뜻 · 하나를 얻기 위해 다른 하나를 포기하는 것
- 예문 · What's the tradeoff if we keep the original date?
- 번역 · 원래 날짜를 지키면 어떤 절충이 필요하나요?

### leave out

- 발음 (미국식 IPA) · /ˌliːv ˈaʊt/
- 뜻 · 포함하지 않고 빼다
- 예문 · We'd have to leave out two reports.
- 번역 · 보고서 두 개를 빼야 합니다.

### target date

- 발음 (미국식 IPA) · /ˈtɑːr.ɡət deɪt/
- 뜻 · 목표로 정한 날짜
- 예문 · The new target date is September 30.
- 번역 · 새 목표 날짜는 9월 30일입니다.

### required

- 발음 (미국식 IPA) · /rɪˈkwaɪɚd/
- 뜻 · 반드시 있어야 하는
- 예문 · If those reports are required, we need the extra two weeks.
- 번역 · 그 보고서가 반드시 필요하다면 2주가 더 필요합니다.

### priority

- 발음 (미국식 IPA) · /praɪˈɔːr.ə.t̬i/
- 뜻 · 먼저 처리해야 하는 중요도
- 예문 · I'll confirm the priority by Thursday.
- 번역 · 목요일까지 우선순위를 확인하겠습니다.

### provisional

- 발음 (미국식 IPA) · /prəˈvɪʒ.ə.nəl/
- 뜻 · 임시로 정한
- 예문 · We'd have to run the first session with a provisional checklist.
- 번역 · 첫 세션을 임시 체크리스트로 진행해야 합니다.

### revise

- 발음 (미국식 IPA) · /rɪˈvaɪz/

- 예문 · We've already revised the document.
- 번역 · 문서는 이미 수정했습니다.

### session

- 발음 (미국식 IPA) · /ˈseʃ.ən/
- 뜻 · 한 번 진행하는 교육이나 회의
- 예문 · We'd have to run the first session with a provisional checklist.
- 번역 · 첫 세션을 임시 체크리스트로 진행해야 합니다.

### start date

- 발음 (미국식 IPA) · /ˈstɑːrt deɪt/
- 뜻 · 일을 시작하는 날짜
- 예문 · The new start date is October 7.
- 번역 · 새 시작 날짜는 10월 7일입니다.

## 발음 포인트

`We've already updated the integration design.`에서 `We've already`는 `weev-all-RED-ee`, `integration design`은 `IN-te-GRAY-shun de-ZINE`처럼 붙여 말합니다. `UP-dat-ed`와 `de-ZINE`을 또렷하게 강조해 이미 끝난 일을 분명히 하세요.

## 응용 대화

A는 HR 리드 Jisoo이고 B는 운영 책임자 Daniel입니다. 법무 검토가 길어져 온보딩 시작일이 늦어지고, 새 날짜와 임시 체크리스트라는 절충안을 논의합니다.

- **A** I want to update you on the onboarding rollout. / We're going to miss the original start date.
  - 온보딩 전개 일정을 업데이트해 드리겠습니다. 원래 시작 날짜를 맞추지 못하게 됐습니다.
- **B** What caused the delay?
  - 지연 원인이 무엇인가요?
- **A** Legal found two issues in the checklist. / We've already revised the document, / but the review is taking longer than expected.
  - 법무에서 체크리스트 문제 두 가지를 찾았습니다. 문서는 이미 수정했지만 검토가 예상보다 오래 걸리고 있습니다.
- **B** How much longer do you need?
  - 얼마나 더 필요하신가요?
- **A** One week. / The new start date is October 7.
  - 1주입니다. 새 시작 날짜는 10월 7일입니다.
- **B** What's the tradeoff if we start on time?
  - 제때 시작하면 어떤 절충이 필요하나요?
- **A** We'd have to run the first session with a provisional checklist. / If that's not acceptable, / we need the extra week. / To hold October 7, / we need your approval by Friday.
  - 첫 세션을 임시 체크리스트로 진행해야 합니다. 그게 받아들여지지 않으면 1주가 더 필요합니다. 10월 7일을 지키려면 금요일까지 승인이 필요합니다.
- **B** Understood. / I'll confirm the priority by Thursday.
  - 알겠습니다. 목요일까지 우선순위를 확인하겠습니다.

지연을 알릴 때는 변명보다 `what caused it`, `what's already done`, `new date`, `what we need` 순서로 말하면 상대가 다음 결정을 내리기 쉽습니다.

## 듣고 답하기

### 1. 지연 원인과 이미 한 일 설명하기

- 상대 음성 · What caused the delay?
- 힌트 · 공급업체가 API를 바꿨고, 통합 설계는 이미 업데이트했지만 테스트가 더 걸린다고 말하세요.
- 예시 답변 · The vendor changed their API last week. We've already updated the integration design, but testing is taking longer than planned.
- 확인 · 원인과 이미 한 일을 구분했나요?

### 2. 새 날짜와 절충안 말하기

- 상대 음성 · How much longer do you need?
- 힌트 · 2주가 더 필요하고 새 목표 날짜는 9월 30일이라고 말한 뒤, 원래 날짜를 지키려면 보고서 두 개를 빼야 한다고 설명하세요.
- 예시 답변 · Two weeks. The new target date is September 30. If we keep the original date, we'd have to leave out two reports.
- 확인 · 새 일정과 절충안을 함께 말했나요?

### 3. 날짜를 지키기 위해 필요한 결정 요청하기

- 상대 음성 · What do you need from us to hold September 30?
- 힌트 · 금요일까지 승인이 필요하다고 말하고, 목요일까지 우선순위를 확인하겠다고 하세요.
- 예시 답변 · We need your approval by Friday. I'll confirm the priority by Thursday.
- 확인 · 필요한 결정과 확인 시점을 분명히 말했나요?

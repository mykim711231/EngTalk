# 16. 제품 데모를 이어서 보여주기 (Continuing a Product Demo)

## 학습 목표

- 과 ID · vol8-16
- 핵심 문법 · G10 진행·완료·결과로 데모 상황 설명하기
- 상황 검색어 · 제품 데모, 로딩 지연, 다음 단계, 데모 요약, 핵심 가치
- 말하기 목표 · 데모가 막히거나 시간이 부족할 때 침착하게 다음 단계를 보여 주고, 지금까지 보여 준 내용과 핵심 가치를 짧게 정리합니다.

## 기본 대화

A는 제품 매니저 Maya이고 B는 고객 Daniel입니다. Maya가 승인 흐름을 시연하다가 데모 데이터가 느리게 로딩되자, 승인 단계로 넘어가 핵심 가치를 설명합니다.

- **A** Thanks for your time today. / I'll show you the new approval flow.
  - 시간 내 주셔서 감사합니다. 새 승인 흐름을 보여 드릴게요.
- **B** Great. / Can you start with the request screen?
  - 좋습니다. 요청 화면부터 보여 주시겠어요?
- **A** Sure. / I'm opening the request screen now. / Sorry, the demo data is loading slowly.
  - 네. 지금 요청 화면을 열고 있습니다. 죄송합니다. 데모 데이터가 느리게 로딩되네요.
- **B** No problem. / We can come back to it.
  - 괜찮습니다. 나중에 다시 보면 되죠.
- **A** Thanks. / While that loads, / I'll move to the approval step, / which is the main change.
  - 감사합니다. 로딩되는 동안, 핵심 변경인 승인 단계로 넘어가겠습니다.
- **B** Okay. / What's different there?
  - 알겠습니다. 거기는 무엇이 다른가요?
- **A** Approvals are now completed on one screen. / We've already tested this with three teams, / and it cut approval time by about thirty percent. / So to summarize, I've shown the request screen and the new approval step, and the main value is speed. / That's the value I want you to see.
  - 승인은 이제 한 화면에서 완료됩니다. 세 팀으로 이미 시험했고, 승인 시간이 약 30퍼센트 줄었습니다. 정리하면 요청 화면과 새 승인 단계를 보여 드렸고, 핵심 가치는 속도입니다. 그게 제가 보여 드리고 싶은 가치예요.
- **B** That's helpful. / The speed is what we need. / Let's come back to the request screen at the end.
  - 도움이 됐습니다. 우리에게 필요한 게 속도예요. 마지막에 요청 화면으로 다시 돌아오죠.

## 문장 구조와 바꿔 말하기

- 대화 문장 · We've already tested this with three teams, and it cut approval time by about thirty percent.
- 문장 구조 · `We`(주어) + `'ve already tested`(현재완료) + `this`(목적어) + `and` + `it`(주어) + `cut`(과거형) + `approval time`(목적어) + `by about thirty percent`(변화 폭)
- 뜻과 어순 · G10에서 이미 끝난 시험 결과는 `have/has + 과거분사`로, 그 결과로 생긴 변화는 과거형 `cut`으로 말합니다. 데모가 막히면 `is loading`처럼 지금 상태를 짧게 알리고, `I'll move to ...`로 다음 단계를 제시합니다. 마지막에는 `To summarize, I've shown ...`으로 지금까지 보여 준 내용을 정리하고 `the value is ...`로 핵심 가치를 다시 말합니다.
- 바꿔 말하기 · 시험을 마쳤다고 말할 때는 `We've completed the pilot.`이라고 합니다. 결과가 좋으면 `It reduced errors by twenty percent.`, 핵심 가치를 말할 때는 `The value is speed without extra errors.`라고 해 보세요.

## 발음 포인트

`We've already tested this with three teams.`에서 `We've already`는 `weev-all-RED-ee`, `tested this`는 `tes-tid-this`처럼 붙여 말합니다. `TEST-ed`와 `THREE TEAMS`를 또렷하게 강조해 시험 규모를 분명히 하세요.

## 응용 대화

A는 제품 매니저 Jisoo이고 B는 운영 책임자 Daniel입니다. 남은 시간이 10분뿐이라 Jisoo가 결제 흐름의 핵심 화면만 보여 주고, 모바일 결과와 핵심 가치를 요약합니다.

- **A** We only have ten minutes left, / so I'll focus on the checkout flow.
  - 10분밖에 남지 않아서 결제 흐름에 집중하겠습니다.
- **B** Sure. / What should we look at first?
  - 좋습니다. 무엇부터 볼까요?
- **A** The new one-page checkout. / We've already seen the order summary, / so I'll skip to payment.
  - 새 한 페이지 결제 화면입니다. 주문 요약은 이미 봤으니 결제 단계로 건너뛰겠습니다.
- **B** Good. / How much faster is it?
  - 좋습니다. 얼마나 빨라졌나요?
- **A** It's about twenty seconds faster per order. / That's a fifteen percent improvement.
  - 주문당 약 20초 빨라졌습니다. 15퍼센트 개선된 거예요.
- **B** And does it work on mobile?
  - 모바일에서도 작동하나요?
- **A** Yes. / The mobile version is already live, / and we've had no major issues in two weeks. / To summarize, I've shown the one-page checkout and the mobile result, and the value is speed without extra errors.
  - 네. 모바일 버전은 이미 공개됐고, 2주 동안 큰 문제가 없었습니다. 정리하면 한 페이지 결제와 모바일 결과를 보여 드렸고, 핵심 가치는 오류 없이 빨라지는 것입니다.
- **B** That's clear. / Let's schedule a deeper demo for the team.
  - 명확합니다. 팀을 위한 더 자세한 데모를 잡죠.

데모가 막히면 사과만 길게 하기보다 `While that loads, I'll move to ...`로 다음 단계를 바로 보여 주고, 마지막에 `To summarize ... the value is ...`로 돌아오면 발표 흐름이 끊기지 않습니다.

## 듣고 답하기

### 1. 데모 문제를 알리고 다음 단계로 넘어가기

- 상대 음성 · Can you start with the request screen?
- 힌트 · 요청 화면을 열지만 데모 데이터가 느리게 로딩된다고 말하고, 승인 단계로 넘어가겠다고 하세요.
- 예시 답변 · Sure. I'm opening the request screen now. Sorry, the demo data is loading slowly. I'll move to the approval step while that loads.
- 확인 · 문제를 인정하고 다음 단계를 제시했나요?

### 2. 보여 준 내용을 요약하고 가치 말하기

- 상대 음성 · What's the main value here?
- 힌트 · 요청 화면과 승인 단계를 보여 줬고, 승인 시간이 30퍼센트 줄었다고 요약하세요.
- 예시 답변 · To summarize, I've shown the request screen and the new approval step. It cut approval time by about thirty percent, so the value is speed.
- 확인 · 요약과 핵심 가치를 함께 말했나요?

### 3. 시간이 부족할 때 핵심으로 돌아오기

- 상대 음성 · We only have five minutes left.
- 힌트 · 결제 흐름의 핵심 화면만 보여 주고, 속도가 가치라고 말하세요.
- 예시 답변 · Then I'll focus on the one-page checkout. The value is speed without extra errors.
- 확인 · 남은 시간에 맞춰 핵심으로 돌아왔나요?

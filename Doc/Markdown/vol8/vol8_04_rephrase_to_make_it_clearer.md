# 04. 같은 말을 이해하기 쉽게 다시 말하기 (Rephrasing to Make It Clearer)

## 학습 목표

- 과 ID · vol8-04
- 핵심 문법 · G12 수동태로 상태와 처리 결과 설명하기
- 상황 검색어 · 다시 말하기, 이해 확인, 복잡한 설명, 데이터 저장, 처리 결과
- 말하기 목표 · 복잡한 설명을 짧고 쉬운 문장으로 다시 말하고, 상대가 이해했는지 확인하며, 원래 말한 사람의 동의를 받습니다.

## 기본 대화

A는 엔지니어 Ryan이고 B는 기획자 Jisoo입니다. Ryan이 두 시스템에 데이터가 나뉘어 저장된 문제를 길게 설명하고, Jisoo가 쉬운 말로 다시 정리해 확인합니다.

- **A** The issue is that our records are kept in two systems, / and the update process isn't fully connected yet.
  - 문제는 저희 기록이 두 시스템에 나뉘어 보관되고, 업데이트 절차가 아직 완전히 연결되지 않았다는 점입니다.
- **B** Okay. / Let me make sure I understand. / So the same data is stored in two places?
  - 알겠습니다. 제가 이해한 게 맞는지 확인해 볼게요. 그러니까 같은 데이터가 두 곳에 저장된다는 거죠?
- **A** Right. / One copy is in the CRM, / and the other is in the billing tool.
  - 맞습니다. 한 사본은 CRM에, 다른 사본은 청구 도구에 있어요.
- **B** Got it. / And the two copies aren't updated at the same time?
  - 알겠습니다. 그리고 두 사본이 동시에 업데이트되지는 않는 거죠?
- **A** Exactly. / The billing copy is updated overnight, / so it can be a day behind.
  - 정확합니다. 청구 사본은 밤에 업데이트되어서 하루 늦을 수 있어요.
- **B** That helps. / So the numbers can be out of date for a day. / Is that accurate?
  - 이해됐습니다. 그러면 숫자가 하루 동안 오래된 상태일 수 있다는 거네요. 맞나요?
- **A** Yes, that's it. / You've summarized it well.
  - 네, 바로 그거예요. 잘 정리해 주셨네요.
- **B** Great. / Then the fix is to connect the two systems.
  - 좋습니다. 그러면 해결책은 두 시스템을 연결하는 것이네요.

## 핵심 문장

### 필수 표현

- Let me make sure I understand.
  - 제가 이해한 게 맞는지 확인해 볼게요.
- So the same data is stored in two places?
  - 그러니까 같은 데이터가 두 곳에 저장된다는 거죠?
- The billing copy is updated overnight.
  - 청구 사본은 밤에 업데이트됩니다.
- Is that accurate?
  - 맞나요?

### 확장 표현

- The issue is that our records are kept in two systems.
  - 문제는 저희 기록이 두 시스템에 나뉘어 보관된다는 점입니다.
- The update process isn't fully connected yet.
  - 업데이트 절차가 아직 완전히 연결되지 않았습니다.
- One copy is in the CRM, and the other is in the billing tool.
  - 한 사본은 CRM에, 다른 사본은 청구 도구에 있습니다.
- The two copies aren't updated at the same time.
  - 두 사본이 동시에 업데이트되지는 않습니다.
- So the numbers can be out of date for a day.
  - 그러면 숫자가 하루 동안 오래된 상태일 수 있겠네요.
- Yes, that's it.
  - 네, 바로 그거예요.
- You've summarized it well.
  - 잘 정리해 주셨네요.
- Then the fix is to connect the two systems.
  - 그러면 해결책은 두 시스템을 연결하는 것입니다.

## 문장 구조와 바꿔 말하기

- 대화 문장 · The billing copy is updated overnight.
- 문장 구조 · `The billing copy`(주어) + `is updated`(be + 과거분사) + `overnight`(때)
- 뜻과 어순 · G12 수동태 `be + 과거분사`는 누가 했는지보다 상태나 처리 결과를 말할 때 씁니다. `The billing copy is updated overnight`는 밤마다 갱신되는 처리 과정을, `The same data is stored in two places`는 데이터가 두 곳에 저장된 상태를 나타냅니다. 행위자가 중요하면 `by the billing team`처럼 `by`로 붙입니다.
- 바꿔 말하기 · 능동문 `We update the billing copy overnight.`를 수동태로 바꾸면 `The billing copy is updated overnight.`입니다. 이미 처리가 끝난 결과는 `The budget has been reduced.`처럼 `has been + 과거분사`로 말해 보세요.

## 발음 포인트

`The billing copy is updated overnight.`에서 `copy is`는 `copy-yis`, `updated overnight`는 `up-dated-overnight`처럼 붙여 말합니다. `BILL-ing`과 `UP-dat-ed`를 또렷하게 강조하고, `overnight`는 뒤쪽 `NIGHT`에 힘을 주어 처리 시점을 분명히 하세요.

## 응용 대화

A는 재무 리드 Daniel이고 B는 프로젝트 매니저 Jisoo입니다. Daniel이 줄어든 예산을 설명하고, Jisoo가 그 영향을 쉬운 말로 다시 정리합니다.

- **A** The budget for this quarter has been reduced, / and some costs have already been committed.
  - 이번 분기 예산이 줄었고, 일부 비용은 이미 확정되어 있습니다.
- **B** Okay. / So the new budget is set, / but part of it is already spent?
  - 알겠습니다. 그러니까 새 예산은 정해졌지만 일부는 이미 지출된 거죠?
- **A** That's right. / The vendor contracts were signed last month.
  - 맞습니다. 공급업체 계약은 지난달에 체결됐어요.
- **B** Got it. / Does that mean the remaining amount is smaller than it looks?
  - 알겠습니다. 그러면 남은 금액이 겉보기보다 적다는 뜻인가요?
- **A** Yes. / About half of the budget is already allocated.
  - 네. 예산의 절반 정도가 이미 배정되어 있어요.
- **B** Let me put it another way. / We have less room to add new work than the total suggests.
  - 다르게 말해 볼게요. 총액이 보여 주는 것보다 새 업무를 추가할 여지가 적다는 거죠.
- **A** Exactly. / That's a clear way to say it.
  - 정확합니다. 명확하게 말씀해 주셨네요.
- **B** Good. / So any new cost needs to be approved before we commit.
  - 좋습니다. 그러면 새 비용은 확정하기 전에 승인을 받아야 하겠네요.

상대의 말을 다시 할 때는 `So you're saying ...`으로 시작하고, 끝에 `Is that accurate?`나 `Am I getting that right?`를 붙이면 오해를 줄일 수 있습니다.

## 듣고 답하기

### 1. 복잡한 설명을 쉬운 말로 다시 하기

- 상대 음성 · Our records are kept in two systems, and the update process isn't fully connected yet.
- 힌트 · 같은 데이터가 두 곳에 저장된다는 뜻인지 확인하고, 두 사본이 동시에 업데이트되는지 물어보세요.
- 예시 답변 · Let me make sure I understand. So the same data is stored in two places? And the two copies aren't updated at the same time?
- 확인 · 복잡한 설명을 짧은 문장으로 나누어 확인했나요?

### 2. 이해한 내용을 확인하고 동의받기

- 상대 음성 · The billing copy is updated overnight, so it can be a day behind.
- 힌트 · 숫자가 하루 늦을 수 있다는 뜻인지 확인하고, 맞는지 물어보세요.
- 예시 답변 · So the numbers can be out of date for a day. Is that accurate?
- 확인 · 상대의 말을 바꿔 말한 뒤 동의를 구했나요?

### 3. 예산 변경을 쉬운 말로 정리하기

- 상대 음성 · The budget has been reduced, and some costs have already been committed.
- 힌트 · 새 예산은 정해졌지만 일부가 이미 지출되었다는 뜻인지 확인하세요.
- 예시 답변 · So the new budget is set, but part of it is already spent?
- 확인 · 수동태로 말한 내용을 상태 중심으로 다시 말했나요?

# 16. 업무 실수를 알리고 수습하기 (Reporting a Mistake and Fixing It)

## 학습 목표

- 과 ID · vol7-16
- 핵심 문법 · G10 진행 중인 일, 끝난 일, 현재 결과로 수습 상황 말하기
- 상황 검색어 · 업무 실수, 잘못 보낸 파일, 영향, 수습, 재발 방지
- 말하기 목표 · 실수를 빠르게 알리고, 이미 고친 일과 지금 하는 일을 구분하며, 영향을 설명하고 재발 방지책과 다음 단계를 확인합니다.

## 기본 대화

A는 매니저 Daniel이고 B는 직원 Jisoo입니다. Jisoo가 고객에게 잘못된 가격표를 보낸 사실을 알리고, 이미 한 조치와 지금 하는 일을 설명합니다.

- **B** Daniel, I need to report a mistake. / I sent the client the wrong price sheet.
  - 대니얼, 실수를 하나 알려 드려야겠어요. 고객에게 잘못된 가격표를 보냈어요.
- **A** Okay. / When did you send it?
  - 알겠어요. 언제 보냈나요?
- **B** About an hour ago. / I've already sent the correct file and apologized.
  - 한 시간 전쯤요. 올바른 파일을 이미 보내고 사과했어요.
- **A** Good. / Did the client see the old prices?
  - 다행이네요. 고객이 예전 가격을 봤나요?
- **B** I'm not sure yet. / I'm calling them now to verify.
  - 아직 확실하지 않아요. 지금 전화해서 확인하고 있어요.
- **A** What's the impact if they did?
  - 고객이 봤다면 영향이 뭔가요?
- **B** They might question the quote. / I've prepared a short explanation, / and I'll double-check the file name as a preventive measure.
  - 견적에 의문을 가질 수 있어요. 짧은 설명을 준비해 뒀고, 재발 방지책으로 파일 이름을 한 번 더 확인할게요.
- **A** Good. / After the call, send me a summary.
  - 좋아요. 통화 후에 요약을 보내 주세요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · I've already sent the correct file and apologized.
- 문장 구조 · `I`(주어) + `'ve already sent`(현재완료) + `the correct file`(목적어) + `and apologized`(이어진 동작)
- 뜻과 어순 · G10에서 현재완료는 끝난 일의 결과가 지금 중요할 때 씁니다. `I've already sent`는 지금 올바른 파일이 고객에게 있다는 뜻입니다. 특정 시점을 말하면 과거형 `I sent it an hour ago`, 지금 하는 중이면 현재진행형 `I'm calling them now`를 씁니다. `already`는 `have`와 과거분사 사이에 둡니다.
- 바꿔 말하기 · 지금 목록을 확인하는 중이면 `I'm checking the client list now.`, 아침에 확인했으면 `I checked it this morning.`, 확인을 마쳐 결과가 있으면 `I've checked it, so the list is clean.`이라고 말해 보세요.

## 발음 포인트

`I've already sent the correct file and apologized.`에서 `I've already`는 `아이브 올레디`처럼 붙여 말하고, `sent the`는 `sen-thuh`로 이어 말합니다. `cor-RECT`와 `a-POL-o-gized`를 또렷하게 강조해 이미 끝낸 조치를 분명히 하세요.

## 응용 대화

고객이 예전 가격을 보고 더 낮은 견적을 요구합니다. A는 매니저이고 B는 Jisoo입니다. 두 사람은 차액을 확인하고 거래를 유지할 방안을 논의합니다.

- **B** The client saw the old prices. / They're asking for the lower quote.
  - 고객이 예전 가격을 봤어요. 더 낮은 견적을 요구하고 있어요.
- **A** I see. / How much is the difference?
  - 그렇군요. 차액이 얼마죠?
- **B** About five percent. / I've explained that it was our mistake.
  - 5퍼센트 정도요. 저희 실수라고 설명했어요.
- **A** Good. / Do you know if they'll accept the corrected price?
  - 좋아요. 수정된 가격을 받아들일지 아세요?
- **B** Not yet. / They want an answer by tomorrow.
  - 아직 모르겠어요. 내일까지 답을 원해요.
- **A** Okay. / Could we offer a small discount to keep the deal?
  - 알겠어요. 거래를 유지하려면 소폭 할인을 제안할 수 있을까요?
- **B** That could work. / I'll propose it and confirm the next step.
  - 그게 통할 수도 있어요. 제안하고 다음 단계를 확인할게요.
- **A** Good. / Send me the summary after the call.
  - 좋아요. 통화 후에 요약을 보내 주세요.

## 듣고 답하기

### 1. 실수와 이미 한 조치 알리기

- 상대 음성 · Did something go wrong with the client file?
- 힌트 · 잘못된 가격표를 보냈다고 말하고, 올바른 파일을 이미 보내고 사과했다고 하세요.
- 예시 답변 · Yes. I sent the wrong price sheet, but I've already sent the correct file and apologized.
- 확인 · 실수와 이미 끝낸 조치를 구분해 말했나요?

### 2. 현재 하는 일과 영향을 설명하기

- 상대 음성 · Did the client see the old prices?
- 힌트 · 아직 모르지만 지금 전화로 확인 중이고, 견적에 의문을 가질 수 있다고 하세요.
- 예시 답변 · I'm not sure yet. I'm calling them now to verify. They might question the quote.
- 확인 · 진행 중인 일과 예상 영향을 함께 말했나요?

### 3. 재발 방지책과 다음 단계 확인하기

- 상대 음성 · Send me a summary after the call.
- 힌트 · 요약을 보내겠다고 답하고, 파일 이름을 다시 확인하겠다는 방지책을 말하세요.
- 예시 답변 · Of course. I'll send the summary, and I'll double-check the file name next time.
- 확인 · 다음 단계와 재발 방지책을 모두 말했나요?

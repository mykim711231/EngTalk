# 11. 전화와 메신저로 긴급도 전하기 (Signaling Urgency by Phone and Chat)

## 학습 목표

- 과 ID · vol7-11
- 핵심 문법 · G10 진행 중인 일과 현재 결과로 긴급 상황 알리기
- 상황 검색어 · 긴급 연락, 시스템 장애, 주문 손실, 처리 시간, 다음 업데이트
- 말하기 목표 · 지금 해결해야 하는 문제와 고객 영향을 전화나 메신저로 알리고, 이미 시도한 조치를 설명하며, 처리 예상 시간과 다음 업데이트를 요청합니다.

## 기본 대화

A는 업체 지원 담당자이고 B는 결제 시스템 장애를 겪는 Jisoo입니다. Jisoo가 전화로 장애를 알리고 영향과 처리 예상 시간을 확인합니다.

- **B** Hi, this is Jisoo from Hanmi Retail. / Our checkout system is down.
  - 안녕하세요, 한미 리테일의 지수입니다. 저희 결제 시스템이 멈췄어요.
- **A** I'm sorry to hear that. / When did the outage start?
  - 안타깝네요. 장애가 언제 시작됐나요?
- **B** About twenty minutes ago. / We're losing orders right now.
  - 약 20분 전부터요. 지금 주문을 놓치고 있어요.
- **A** Okay. / I'm checking the logs now. / We're working to resolve it.
  - 알겠습니다. 지금 로그를 확인하고 있어요. 해결하려고 작업 중입니다.
- **B** Thanks. / Could you tell me how long a fix will take?
  - 감사합니다. 수리에 얼마나 걸릴지 알려 주시겠어요?
- **A** I don't have an ETA yet, / but I've raised it with our engineering team.
  - 아직 정확한 시간은 모르지만, 엔지니어링 팀에 올려 뒀어요.
- **B** Please update me every thirty minutes. / This is affecting paying customers.
  - 30분마다 알려 주세요. 유료 고객에게 영향이 가고 있어요.
- **A** Understood. / I'll send you an update by 2:30.
  - 알겠습니다. 2시 30분까지 업데이트를 보내 드릴게요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · We're losing orders right now.
- 문장 구조 · `We`(주어) + `'re losing`(현재진행형) + `orders`(목적어) + `right now`(지금)
- 뜻과 어순 · G10은 상황에 따라 시제를 고릅니다. 지금 벌어지는 일은 현재진행형 `We're losing orders right now`, 이미 끝난 조치는 현재완료 `I've raised it with our engineering team`, 특정 시점에 일어난 일은 과거형 `The outage started twenty minutes ago`로 말합니다. 긴급할수록 지금 진행 중인 일과 이미 끝난 조치를 구분해 전달합니다.
- 바꿔 말하기 · 지금 원인을 찾고 있으면 `We're looking into it now.`, 10분 전에 찾았으면 `We found the cause ten minutes ago.`, 찾아서 조치할 수 있으면 `We've found the cause, so we can start the fix.`라고 말해 보세요.

## 주요 단어와 표현

긴급한 문제를 알리고 처리 상황을 확인할 때 쓰는 표현을 정리합니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### checkout system

- 발음 (미국식 IPA) · /ˈtʃek.aʊt ˈsɪs.təm/
- 뜻 · 고객이 결제를 마치는 온라인 시스템
- 예문 · Our checkout system is down.
- 번역 · 저희 결제 시스템이 멈췄어요.

### down

- 발음 (미국식 IPA) · /daʊn/
- 뜻 · 시스템이나 서비스가 작동하지 않는
- 예문 · The checkout system is down.
- 번역 · 결제 시스템이 작동하지 않아요.

### outage

- 발음 (미국식 IPA) · /ˈaʊ.tɪdʒ/
- 뜻 · 시스템이나 서비스가 멈춘 장애 상태
- 예문 · When did the outage start?
- 번역 · 장애가 언제 시작됐나요?

### logs

- 발음 (미국식 IPA) · /lɔːɡz/
- 뜻 · 시스템 작동 기록을 남긴 자료
- 예문 · I'm checking the logs now.
- 번역 · 지금 로그를 확인하고 있어요.

### fix

- 발음 (미국식 IPA) · /fɪks/
- 뜻 · 고장 난 것을 고치는 일이나 해결책
- 예문 · How long will the fix take?
- 번역 · 수리에 얼마나 걸리나요?

### resolve

- 발음 (미국식 IPA) · /rɪˈzɑːlv/
- 뜻 · 문제를 완전히 해결하다
- 예문 · We're working to resolve it.
- 번역 · 해결하려고 작업 중입니다.

### ETA

- 발음 (미국식 IPA) · /ˌiː tiː ˈeɪ/
- 뜻 · 완료나 도착까지 걸리는 예상 시간
- 예문 · I don't have an ETA yet.
- 번역 · 아직 예상 시간은 몰라요.

### raise

- 발음 (미국식 IPA) · /reɪz/
- 뜻 · 문제를 상위 담당자나 팀에 알리다
- 예문 · I've raised it with our engineering team.
- 번역 · 엔지니어링 팀에 올려 뒀어요.

### engineering team

- 발음 (미국식 IPA) · /ˌen.dʒəˈnɪr.ɪŋ tiːm/
- 뜻 · 기술적인 문제를 고치는 개발·기술 팀
- 예문 · The engineering team is on it.
- 번역 · 엔지니어링 팀이 처리하고 있어요.

### update

- 발음 (미국식 IPA) · /ˈʌp.deɪt/
- 뜻 · 진행 상황을 알려 주는 새로운 소식
- 예문 · I'll send you an update by 2:30.
- 번역 · 2시 30분까지 업데이트를 보내 드릴게요.

### affecting

- 발음 (미국식 IPA) · /əˈfekt.ɪŋ/
- 뜻 · 어떤 대상에게 영향을 주고 있는
- 예문 · This is affecting paying customers.
- 번역 · 유료 고객에게 영향이 가고 있어요.

### paying customers

- 발음 (미국식 IPA) · /ˈpeɪ.ɪŋ ˈkʌs.tə.mɚz/
- 뜻 · 실제로 돈을 내고 서비스를 쓰는 고객
- 예문 · Paying customers can't check out.
- 번역 · 유료 고객이 결제를 못 하고 있어요.

## 발음 포인트

`I've raised it with our engineering team.`에서 `raised it`은 `raised-it`처럼 붙여 말하고, `with our`는 `with-our`로 이어 말합니다. `ENGINEERING`은 `en-ji-NEER-ing`처럼 세 번째 음절을 강조하고, `TEAM`을 또렷하게 말하세요.

## 응용 대화

업체가 메신저로 오류 코드와 추가 정보를 요청합니다. A는 업체 담당자이고 B는 Jisoo입니다. 두 사람은 임시 대안과 다음 업데이트 시점을 정합니다.

- **A** Hi, Jisoo. / Can you send me the error code from the checkout page?
  - 안녕하세요, 지수 씨. 결제 페이지의 오류 코드를 보내 주시겠어요?
- **B** Sure. / It's E-5023. / I'm sending a screenshot now.
  - 네. E-5023이에요. 지금 스크린샷을 보내고 있어요.
- **A** Got it. / Have you tried clearing the cache?
  - 받았어요. 캐시를 지워 보셨나요?
- **B** Yes. / We've already tried that, / and the error is still there.
  - 네. 이미 해 봤는데 오류가 계속 나요.
- **A** Okay. / We can switch you to a backup payment page. / I'm setting that up now.
  - 알겠습니다. 백업 결제 페이지로 전환해 드릴 수 있어요. 지금 준비하고 있어요.
- **B** That would help. / How soon can we use it?
  - 그게 도움이 되겠네요. 언제쯤 쓸 수 있나요?
- **A** In about ten minutes. / I'll send you the link.
  - 10분 정도면 돼요. 링크를 보내 드릴게요.
- **B** Great. / Please update us again by three.
  - 좋습니다. 3시까지 다시 알려 주세요.

## 복습

1. 시스템 장애를 알리는 문장을 고르세요.
   - A. Our checkout system is down.
   - B. The meeting is at 2:30.
   - C. I'll send the report Friday.
   - D. Who is the client?
2. 수리에 얼마나 걸릴지 간접 질문으로 물어보세요.
3. 지금 고객에게 어떤 영향이 있나요?
4. 응용 대화에서 임시 대안은 무엇인가요?

### 정답과 예시 답변

- 1번 · A
- 2번 · `Could you tell me how long a fix will take?`
- 3번 · 주문을 놓치고 있고, 유료 고객에게 영향이 갑니다.
- 4번 · 백업 결제 페이지로 전환하는 것입니다.

## 듣고 답하기

### 1. 장애 상황과 영향 알리기

- 상대 음성 · Hi, this is Daniel from vendor support. What's the problem?
- 힌트 · 결제 시스템이 멈췄고 지금 주문을 놓치고 있다고 급하게 알리세요.
- 예시 답변 · Our checkout system is down. We're losing orders right now.
- 확인 · 문제와 현재 영향을 함께 말했나요?

### 2. 처리 예상 시간 묻기

- 상대 음성 · I'm checking the logs now. We're working to resolve it.
- 힌트 · 수리에 얼마나 걸릴지 정중하지만 급하게 물어보세요.
- 예시 답변 · Thanks. Could you tell me how long a fix will take?
- 확인 · 긴급도를 유지하며 간접 질문으로 물었나요?

### 3. 다음 업데이트 약속하기

- 상대 음성 · I'll send you an update as soon as I have more information.
- 힌트 · 30분마다 업데이트를 달라고 요청하고, 다음 시각을 확인하세요.
- 예시 답변 · Please update me every thirty minutes. Can you confirm the next update time?
- 확인 · 알림 주기와 다음 시각을 분명히 했나요?

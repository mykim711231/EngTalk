# 09. 업무 파일 링크와 접근 권한 보내기 (Sharing File Links and Access)

## 학습 목표

- 과 ID · vol7-09
- 핵심 문법 · G11 간접 질문으로 이메일과 접근 권한 확인하기
- 상황 검색어 · 파일 링크, 접근 권한, 보기 권한, 편집 권한, 다운로드
- 말하기 목표 · 파일 링크를 보내고 접근이 되는지 확인하며, 필요한 권한 수준을 설명하고 요청합니다.

## 기본 대화

A는 링크를 받은 동료 Ryan이고 B는 파일을 공유하는 Jisoo입니다. Ryan이 링크를 열지 못하자 두 사람이 이메일 주소와 권한 수준을 확인합니다.

- **B** I've shared the project folder with you. / Can you open this link?
  - 프로젝트 폴더를 공유했어요. 이 링크를 열 수 있나요?
- **A** Let me try. / It says I need permission.
  - 해 볼게요. 권한이 필요하다고 나와요.
- **B** Okay. / Could you tell me which email you use for work?
  - 알겠어요. 업무용으로 어떤 이메일을 쓰는지 알려 주시겠어요?
- **A** It's ryan.kim@ourcompany.com.
  - ryan.kim@ourcompany.com이에요.
- **B** Got it. / What access level do you need—edit access or view?
  - 알겠어요. 어떤 권한이 필요하세요? 편집 권한인가요, 보기인가요?
- **A** View is fine for now. / Could you tell me if I can download the files?
  - 지금은 보기만으로 충분해요. 파일을 다운로드할 수 있는지 알려 주시겠어요?
- **B** Yes, viewing includes download. / I'll notify you when the new link is ready.
  - 네, 보기 권한에 다운로드도 포함돼요. 새 링크가 준비되면 알려 드릴게요.
- **A** Thanks. / Let me know if you need my employee ID.
  - 감사합니다. 직원 번호가 필요하면 알려 주세요.

## 핵심 문장

### 필수 표현

- Could you tell me which email you use for work?
  - 업무용으로 어떤 이메일을 쓰는지 알려 주시겠어요?
- Could you tell me if I can download the files?
  - 파일을 다운로드할 수 있는지 알려 주시겠어요?
- What access level do you need—edit access or view?
  - 어떤 권한이 필요하세요? 편집 권한인가요, 보기인가요?
- I'll notify you when the new link is ready.
  - 새 링크가 준비되면 알려 드릴게요.

### 확장 표현

- I've shared the project folder with you.
  - 프로젝트 폴더를 공유했어요.
- Can you open this link?
  - 이 링크를 열 수 있나요?
- It says I need permission.
  - 권한이 필요하다고 나와요.
- I'll add that address.
  - 그 주소를 추가할게요.
- View is fine for now.
  - 지금은 보기만으로 충분해요.
- Viewing includes download.
  - 보기 권한에 다운로드도 포함돼요.
- You can request access from the folder owner.
  - 폴더 소유자에게 접근 권한을 요청할 수 있어요.
- The link expires in seven days.
  - 링크는 7일 후에 만료돼요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · Could you tell me which email you use for work?
- 문장 구조 · `Could you tell me`(정중한 요청) + `which email`(의문사 + 명사) + `you`(주어) + `use`(동사) + `for work`(용도)
- 뜻과 어순 · 직접 질문 `Which email do you use for work?`에는 `do`가 주어 앞에 옵니다. G11 간접 질문에서는 `do`를 빼고 `which email you use for work`처럼 의문사 뒤에 평서문 어순을 씁니다. 예·아니오로 답하는 내용은 `if`로 잇습니다.
- 바꿔 말하기 · 파일을 내려받을 수 있는지 물으려면 `Could you tell me if I can download the files?`라고 합니다. 링크 만료 시점을 물을 때는 `Do you know when the link expires?`처럼 의문사 뒤에 주어와 동사를 둡니다.

## 주요 단어와 표현

파일을 공유하고 접근 권한을 맞출 때 쓰는 표현을 정리합니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### link

- 발음 (미국식 IPA) · /lɪŋk/
- 뜻 · 파일이나 폴더로 이동하는 인터넷 주소
- 예문 · Can you open this link?
- 번역 · 이 링크를 열 수 있나요?

### access level

- 발음 (미국식 IPA) · /ˈæk.ses ˌlev.əl/
- 뜻 · 자료를 어디까지 다룰 수 있는지 정한 권한 단계
- 예문 · What access level do you need?
- 번역 · 어떤 권한이 필요한가요?

### edit access

- 발음 (미국식 IPA) · /ˈed.ɪt ˈæk.ses/
- 뜻 · 내용을 고치고 저장할 수 있는 권한
- 예문 · Do you need edit access?
- 번역 · 편집 권한이 필요한가요?

### view

- 발음 (미국식 IPA) · /vjuː/
- 뜻 · 내용을 보기만 할 수 있는 권한
- 예문 · View is fine for now.
- 번역 · 지금은 보기만으로 충분해요.

### download

- 발음 (미국식 IPA) · /ˈdaʊn.loʊd/
- 뜻 · 파일을 내 컴퓨터나 기기로 저장하다
- 예문 · Can I download the files?
- 번역 · 파일을 다운로드해도 되나요?

### address

- 발음 (미국식 IPA) · /əˈdres/
- 뜻 · 이메일을 받는 전자 우편 주소
- 예문 · I'll add that address.
- 번역 · 그 주소를 추가할게요.

### employee ID

- 발음 (미국식 IPA) · /ɪmˈplɔɪ.iː ˌaɪˈdiː/
- 뜻 · 회사가 직원에게 부여한 식별 번호
- 예문 · Let me know if you need my employee ID.
- 번역 · 직원 번호가 필요하면 알려 주세요.

### permission

- 발음 (미국식 IPA) · /pɚˈmɪʃ.ən/
- 뜻 · 파일이나 시스템을 열어 쓸 수 있게 주는 허가
- 예문 · It says I need permission.
- 번역 · 권한이 필요하다고 나와요.

### expires

- 발음 (미국식 IPA) · /ɪkˈspaɪɚz/
- 뜻 · 정해진 기간이 지나 더 이상 쓸 수 없게 되다
- 예문 · The link expires in seven days.
- 번역 · 링크는 7일 후에 만료돼요.

### request access

- 발음 (미국식 IPA) · /rɪˈkwest ˈæk.ses/
- 뜻 · 자료를 쓸 수 있도록 권한을 신청하다
- 예문 · You can request access from the folder owner.
- 번역 · 폴더 소유자에게 접근 권한을 요청할 수 있어요.

### owner

- 발음 (미국식 IPA) · /ˈoʊ.nɚ/
- 뜻 · 파일이나 폴더를 만들고 관리하는 사람
- 예문 · Ask the folder owner for access.
- 번역 · 폴더 소유자에게 권한을 요청하세요.

### notify

- 발음 (미국식 IPA) · /ˈnoʊ.t̬ə.faɪ/
- 뜻 · 준비되거나 바뀐 사실을 알리다
- 예문 · I'll notify you when the new link is ready.
- 번역 · 새 링크가 준비되면 알려 드릴게요.

## 발음 포인트

`Could you tell me which email you use for work?`에서 `which email`은 `which-email`처럼 붙여 말하고, `tell me`는 `tel-me`로 이어 말합니다. `USE`와 `WORK`를 또렷하게 강조해 묻는 내용을 분명히 하세요.

## 응용 대화

A의 회사가 외부 링크를 차단해 폴더가 계속 열리지 않습니다. B는 IT팀에 도메인 허용을 요청하고, 그동안 파일을 첨부 파일로 보내는 대안을 제안합니다.

- **A** I still can't open the folder. / Our company blocks outside links.
  - 폴더가 여전히 안 열려요. 저희 회사가 외부 링크를 차단하거든요.
- **B** I see. / Could you tell me what error you see?
  - 그렇군요. 어떤 오류가 보이는지 알려 주시겠어요?
- **A** It says the domain isn't allowed.
  - 도메인이 허용되지 않는다고 나와요.
- **B** Okay. / I'll ask IT to allow your domain.
  - 알겠어요. IT팀에 귀사 도메인을 허용해 달라고 할게요.
- **A** Thanks. / Do you know how long that usually takes?
  - 감사합니다. 보통 얼마나 걸리는지 아세요?
- **B** About a day. / In the meantime, / I can send the files as attachments.
  - 하루 정도요. 그동안에는 파일을 첨부 파일로 보내 드릴 수 있어요.
- **A** That works. / Could you send the main report first?
  - 그게 좋겠어요. 주요 보고서를 먼저 보내 주시겠어요?
- **B** Sure. / I'll send it in the next ten minutes.
  - 물론이죠. 10분 안에 보낼게요.

## 복습

1. 필요한 접근 권한 수준을 묻는 문장을 고르세요.
   - A. What access level do you need—edit access or view?
   - B. Where is the folder?
   - C. Who wrote the report?
   - D. When is the meeting?
2. 업무용 이메일을 간접 질문으로 물어보세요.
3. 보기 권한에 포함되는 것은 무엇인가요?
4. 응용 대화에서 링크가 열리지 않는 이유는 무엇인가요?

## 듣고 답하기

### 1. 이메일 주소 확인하기

- 상대 음성 · It says I need permission.
- 힌트 · 업무용으로 어떤 이메일을 쓰는지 정중하게 물어보세요.
- 예시 답변 · Okay. Could you tell me which email you use for work?
- 확인 · which를 사용한 간접 질문으로 물었나요?

### 2. 권한 수준 정하기

- 상대 음성 · I need to add a few comments to the document.
- 힌트 · 편집 권한이 필요한지 확인하세요.
- 예시 답변 · Got it. Do you need edit access or just view?
- 확인 · 필요한 권한 수준을 분명히 확인했나요?

### 3. 다운로드 가능 여부 확인하기

- 상대 음성 · View is fine for now.
- 힌트 · 보기 권한으로 파일을 다운로드할 수 있는지 물어보세요.
- 예시 답변 · Could you tell me if I can download the files?
- 확인 · if를 사용한 간접 질문으로 물었나요?

# 15. 학습과 원격교육 방식 비교하기 (Comparing Classroom and Remote Learning)

## 학습 목표

- 과 ID · vol11-15
- 핵심 문법 · G15 양보와 대조, G17 근거와 결론으로 대면수업과 원격수업 비교하기
- 상황 검색어 · 대면수업, 원격수업, 하이브리드, 학습자 차이, 근거의 한계, 조건부 입장
- 말하기 목표 · 대면수업과 원격수업이 어떤 학습자에게 맞는지 비교하고, 근거가 엇갈리는 부분을 인정한 뒤, 조건을 붙여 권고합니다.

## 기본 대화

A는 Hannah, B는 Diego입니다. 학군이 내년에 주 1회 원격 수업을 유지하려 하자, 교사 Hannah와 학부모 Diego가 학생별 차이를 이야기합니다.

- **A** The district wants to keep one remote day a week next year. / I'm not sure that's a good idea.
  - 학군이 내년에 주 1회 원격 수업을 유지하려 해. 좋은 생각인지 잘 모르겠어.
- **B** For which students?
  - 어떤 학생들에게?
- **A** That's the problem—there's no single answer. / Some do better at home; others need the classroom.
  - 그게 문제야. 하나의 답이 없어. 집에서 더 잘하는 학생도 있고, 교실이 필요한 학생도 있어.
- **B** My son needs the structure. / At home, he just stops working.
  - 우리 아들은 규칙이 필요해. 집에서는 그냥 하던 걸 멈춰.
- **A** And I have students who focus better without the noise. / The evidence is mixed.
  - 나는 소음이 없을 때 더 집중하는 학생들도 있어. 근거가 엇갈려.
- **B** So what should the district do?
  - 그럼 학군은 어떻게 해야 해?
- **A** Maybe make the remote day optional by class, not district-wide.
  - 원격 수업을 학군 전체가 아니라 학급별로 선택하게 하는 건 어때?
- **B** That sounds harder to run, but fairer.
  - 운영은 더 어려워 보이지만 더 공평하네.

- My son needs the structure.

## 문장 구조와 바꿔 말하기

- 대화 문장 · Given the mixed evidence, a district-wide rule is hard to defend.
- 문장 구조 · `Given`(근거) + `the mixed evidence`(근거 명사구) + `a district-wide rule`(주어) + `is`(동사) + `hard to defend`(보어)
- 뜻과 어순 · G17에서 `Given ...`은 근거가 결론을 어디까지 지지하는지 밝힐 때 씁니다. G15에서는 `While remote days help some students, they leave others behind.`처럼 한쪽의 편익을 인정하고 다른 쪽의 비용을 붙입니다. 교육 연구는 `learner`마다 조건이 달라 결과가 엇갈리므로, `The evidence is mixed.`와 `It depends on the learner.`로 한계를 먼저 말합니다. 조건부 권고는 `I'd support it only if ...`, `provided that ...`, `by grade level`로 범위를 좁혀 제시합니다. `track outcomes`는 시행 뒤 결과를 계속 확인한다는 뜻으로, 근거가 부족할 때 무리한 확대를 피하는 표현입니다.
- 바꿔 말하기 · 학습자 차이를 근거로 들 때는 `Given how differently students learn, one rule won't fit all.`, 양보하며 우려를 붙일 때는 `While remote days work for some, they leave others behind.`, 조건을 달 때는 `I'd support it only if each class can opt out.`라고 해 보세요.

## 발음 포인트

`Given the mixed evidence, a district-wide rule is hard to defend.`에서 `Given the`는 `GIV-ən-thə`, `mixed evidence`는 `MIKST-EV-ə-dəns`처럼 붙여 말합니다. `district-wide`는 `DIS-trict-WIDE`로 두 부분을 살리고, `hard to`는 `HAR-də`로 약하게 줄이세요. 강조는 `MIXED`, `DIS-trict-WIDE`, `HARD`, `deFEND`에 두면 근거의 한계와 결론이 분명해집니다. `routine`은 /ruːˈtiːn/로 둘째 음절 `TEEN`을 길게, `supervision`은 /ˌsuː.pɚˈVĪZH-ən/으로 `VIZH`를 살려 말하세요.

## 응용 대화

A는 Hannah, B는 Diego입니다. 이사회가 하이브리드 일정을 학군 전체로 확대하려 하자, 두 사람은 학년별 선택과 결과 추적을 조건으로 권고안을 만듭니다.

- **A** The board meeting is Tuesday. / They want a recommendation on the hybrid schedule.
  - 이사회가 화요일이야. 하이브리드 일정에 대한 권고를 원해.
- **B** Are you going to support it?
  - 너는 지지할 거야?
- **A** Only if it's flexible. / One remote day can work for older students who manage their time.
  - 유연할 때만. 원격 하루는 시간을 관리하는 나이 든 학생들에게는 통할 수 있어.
- **B** And for younger ones?
  - 어린 학생들은?
- **A** They need supervision and a routine. / For them, remote days often become lost days.
  - 감독과 일정한 생활 리듬이 필요해. 그런 학생들에게 원격 수업은 자주 잃어버린 날이 돼.
- **B** So what do you recommend?
  - 그래서 뭘 권고할 거야?
- **A** Keep the hybrid option, but let each school decide by grade. / And track outcomes for a year before expanding.
  - 하이브리드 선택은 유지하되 학교별로 학년에 따라 정하게 해. 그리고 확대 전에 1년간 결과를 추적해.
- **B** That's defensible. / It admits we don't know yet.
  - 그건 옹호할 수 있겠네. 아직 모른다는 걸 인정하는 거니까.

권고안을 만들 때는 `Only if it's flexible.`로 조건을 먼저 밝히고, `let each school decide by grade`처럼 결정 단위를 좁힙니다. `track outcomes for a year before expanding`을 붙이면, 근거가 엇갈리는 상태에서도 무리한 확대를 피하면서 배울 여지를 남길 수 있습니다.

## 듣고 답하기

### 1. 학습자별 차이 비교하기

- 상대 음성 · Is remote learning better for students?
- 힌트 · 하나의 답이 없다고 말하고, 잘 맞는 학생과 어려운 학생을 나눠 설명하세요.
- 예시 답변 · There's no single answer. It works for students who manage their own time, but it's harder for students who need supervision.
- 확인 · 학습자 차이를 양쪽으로 설명했나요?

### 2. 근거의 한계 인정하기

- 상대 음성 · But the research clearly supports remote days.
- 힌트 · 근거가 엇갈린다고 말하고, 그래서 전체 규칙을 정하기 어렵다고 설명하세요.
- 예시 답변 · The evidence is mixed. Given that, a district-wide rule is hard to defend, because it depends on the learner.
- 확인 · 근거의 한계를 인정하며 결론을 낮췄나요?

### 3. 조건부 권고 만들기

- 상대 음성 · Should we keep the hybrid schedule next year?
- 힌트 · 유연한 운영과 학년별 결정, 결과 추적을 조건으로 붙이세요.
- 예시 답변 · I'd keep it only if each school can decide by grade and we track outcomes for a year before expanding.
- 확인 · 조건과 범위를 분명히 했나요?

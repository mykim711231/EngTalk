# 16. 렌터카 인수와 반납 조건 확인하기 (Checking Rental Car Pickup and Return Terms)

## 학습 목표

- 과 ID · vol4-16
- 핵심 문법 · G09 if를 써서 반납 조건 확인하기
- 상황 검색어 · 렌터카, 인수, 반납, 연료, 영업시간 이후, 열쇠 반납함
- 말하기 목표 · 차를 받을 때 연료 상태와 반납 장소를 확인하고 문 닫은 뒤 반납할 수 있는지 물어봅니다.

## 기본 대화

B가 예약한 차를 인수합니다. A는 렌터카 업체 직원입니다.

- **A** Are you here to pick up a rental car?
  - 렌터카를 받으러 오셨나요?
- **B** Yes. Where do I pick up the car?
  - 네. 차는 어디에서 받나요?
- **A** It's in space twelve in the parking garage.
  - 주차장 십이 번 자리에 있어요.
- **B** Do I need to return it to the same location?
  - 반납도 같은 장소로 해야 하나요?
- **A** Yes, please return it here.
  - 네, 여기로 반납해 주세요.
- **B** Should I bring it back with a full tank?
  - 연료를 가득 채워 반납해야 하나요?
- **A** Yes. It has a full tank now.
  - 네. 지금 연료가 가득 차 있어요.
- **B** Okay. I'll check before I drive off.
  - 알겠습니다. 출발하기 전에 확인할게요.

## 핵심 문장

### 필수 표현

## 문장 구조와 바꿔 말하기

- 대화 문장 · What if I arrive after closing?
- 문장 구조 · `What if`(어떻게 하나요) + `I arrive`(내가 도착한다면) + `after closing`(업체가 문을 닫은 뒤)
- 뜻과 어순 · `What if …?`로 특정 상황에서 어떻게 해야 하는지 물을 수 있습니다. 같은 상황에서 반납이 가능한지만 묻고 싶으면 `Can I return it after hours?`라고 합니다.
- 바꿔 말하기 · 아침 일찍 반납하려면 `What if I arrive before the office opens?`라고 물으세요.

## 발음 포인트

`PICK UP the car`와 `reTURN it`을 번갈아 말해 보세요. 어느 행동에 관한 장소와 시각인지 상대가 구분할 수 있도록 동사를 또렷하게 말합니다.

## 응용 대화

B의 일정이 늦어져 업체가 문을 닫은 뒤 차를 반납할 수 있는지 확인합니다.

- **A** Do you have any questions about the return?
  - 반납에 관해 질문이 있으세요?
- **B** Yes. Can I return it after hours?
  - 네. 영업시간이 지난 뒤 반납할 수 있나요?
- **A** Yes, this location has an after-hours return area.
  - 네, 이 지점에는 영업시간 외 반납 구역이 있어요.
- **B** Where do I leave the keys?
  - 열쇠는 어디에 두나요?
- **A** Use the key drop by the door. Follow the signs first.
  - 문 옆 열쇠 반납함에 넣으세요. 먼저 안내 표지판을 따라가세요.
- **B** Okay. Could you show me the return instructions?
  - 알겠습니다. 차량 반납 안내를 보여 주실래요?

반납은 지점마다 운영시간과 방법이 다를 수 있습니다. 열쇠를 어디에 둘지, 어느 주차 구역으로 들어갈지 실제 안내를 확인하세요.

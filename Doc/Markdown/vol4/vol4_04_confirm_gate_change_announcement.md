# 04. 탑승구 변경 방송 확인하기 (Confirming a Gate-Change Announcement)

## 학습 목표

- 과 ID · vol4-04
- 핵심 문법 · G06 from과 to로 탑승구 변경의 새 위치 듣기
- 상황 검색어 · 탑승구 변경, 공항 방송, 항공편 번호, 탑승 시각, 최종 호출
- 말하기 목표 · 공항 방송에서 항공편 번호와 새 탑승구를 찾아내고, 탑승 시작 시각도 다시 확인합니다.

## 기본 대화

여행자 A가 방송을 듣습니다. 같은 항공편을 기다리는 B가 앞부분을 놓쳐 내용을 확인합니다.

- **A** Did you hear that announcement?
  - 방금 방송 들으셨어요?
- **B** I missed the first part. Which flight was it for?
  - 앞부분을 놓쳤어요. 어느 항공편이었어요?
- **A** It was for Flight two forty-six to Seattle.
  - 시애틀행 246편 안내였어요.
- **B** Did the gate change?
  - 탑승구가 바뀌었나요?
- **A** Yes, we're now leaving from Gate B twelve.
  - 네, 이제 B12에서 출발해요.
- **B** What time does boarding start?
  - 탑승이 몇 시에 시작하나요?
- **A** Boarding starts at four fifteen.
  - 네 시 십오 분에 탑승이 시작돼요.
- **B** B twelve at four fifteen. Thanks.
  - 네 시 십오 분에 B12군요. 감사합니다.

## 핵심 문장

### 필수 표현

- Which flight was it for?
  - 어느 항공편 안내였어요?
- Did the gate change?
  - 탑승구가 바뀌었나요?
- We're now leaving from Gate B twelve.
  - 이제 B12에서 출발해요.
- What time does boarding start?
  - 탑승이 몇 시에 시작하나요?

### 확장 표현

- I missed the first part.
  - 앞부분을 놓쳤어요.
- Please proceed to Gate C seven.
  - C7 탑승구로 이동해 주세요.
- Is that B twelve or D twelve?
  - B12인가요, D12인가요?
- It's B as in boy.
  - boy의 첫 글자 B예요.
- Check the departure board.
  - 출발 안내 전광판을 확인하세요.
- This is the final boarding call.
  - 마지막 탑승 안내입니다.

## 문장 구조와 바꿔 말하기

- 대화 문장 · We're now leaving from Gate B twelve.
- 문장 구조 · `We`(주어) + `are now leaving`(이제 출발한다) + `from Gate B twelve`(새로 출발하는 탑승구)
- 뜻과 어순 · `from Gate B twelve`는 출발하는 탑승구입니다. `Please proceed to Gate C seven.`에서 `to` 다음에는 이동할 새 탑승구가 나옵니다.
- 바꿔 말하기 · 새 탑승구를 `C seven`으로 바꿔 다른 승객에게 알려 주세요.

## 발음 포인트

`B twelve`와 `D twelve`를 번갈아 들어 보세요. 헷갈리는 글자는 `B as in boy`처럼 한 단어를 예로 들어 분명히 말할 수 있습니다.

## 응용 대화

A와 B가 같은 항공편의 새 탑승구 표기를 놓고 확인합니다. 휴대전화 화면과 전광판을 함께 봅니다.

- **A** My phone says our gate changed.
  - 제 휴대전화에는 탑승구가 바뀌었다고 나와요.
- **B** Is that B twelve or D twelve?
  - B12인가요, D12인가요?
- **A** It's B as in boy.
  - boy의 첫 글자 B예요.
- **B** Are you sure it shows Flight two forty-six?
  - 정말 246편을 보여 주고 있나요?
- **A** Yes. Check the departure board, too.
  - 네. 출발 전광판도 확인해 보세요.
- **B** It says B twelve there, too. Let's go.
  - 거기에도 B12라고 나와요. 가요.

공항에는 같은 도시로 가는 항공편이 여러 개 있을 수 있습니다. 목적지뿐 아니라 내 항공편 번호를 함께 확인하세요.

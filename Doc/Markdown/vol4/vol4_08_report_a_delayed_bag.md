# 08. 수하물이 도착하지 않았다고 신고하기 (Reporting Baggage That Hasn’t Arrived)

## 학습 목표

- 과 ID · vol4-08
- 핵심 문법 · G10 hasn't와 과거분사로 아직 짐이 안 나온 상태 말하기
- 상황 검색어 · 수하물 미도착, 찾는 곳, 가방 태그, 수하물 신고, 접수 번호
- 말하기 목표 · 수하물 미도착을 알리고 태그와 가방 특징을 제공하며 후속 연락 방법을 확인합니다.

## 기본 대화

B의 여행 가방이 수하물 벨트에 나오지 않았습니다. A는 항공사 수하물 담당자입니다.

- **A** How can I help you?
  - 무엇을 도와드릴까요?
- **B** My checked bag hasn't arrived.
  - 제가 부친 짐이 나오지 않았어요.
- **A** Do you have your baggage tag receipt?
  - 수하물표 접수증이 있나요?
- **B** Yes, here it is.
  - 네, 여기요.
- **A** What does your bag look like?
  - 가방이 어떻게 생겼나요?
- **B** It's a black suitcase with a yellow strap.
  - 노란 띠가 둘러진 검은 여행 가방이에요.
- **A** All right. We can file a baggage report.
  - 알겠습니다. 수하물 신고를 접수할 수 있어요.
- **B** Thank you. Could I get a reference number?
  - 감사합니다. 접수 번호를 받을 수 있나요?

## 문장 구조와 바꿔 말하기

- 대화 문장 · My checked bag hasn't arrived.
- 문장 구조 · `My checked bag`(주어) + `hasn't arrived`(지금까지 도착하지 않았다)
- 뜻과 어순 · `hasn't arrived`는 현재까지도 받지 못했다는 뜻입니다. 신고할 때는 `black suitcase with a yellow strap`처럼 물건의 특징도 같이 말합니다.
- 바꿔 말하기 · 여행 가방 대신 작은 상자가 아직 도착하지 않았다고 말하세요. `My box hasn't arrived.`

## 응용 대화

B는 신고한 뒤 짐을 찾으면 어디로 보내는지와 진행 확인 방법을 묻습니다.

- **A** What's the best number to reach you?
  - 연락받기 좋은 전화번호가 어떻게 되나요?
- **B** Here's my number. Can you send it to my hotel if you find it?
  - 여기 제 번호예요. 찾으면 제 호텔로 보낼 수 있나요?
- **A** We can note the hotel address on the report.
  - 신고서에 호텔 주소를 적을 수 있어요.
- **B** I'll write down the address. How can I check the status?
  - 주소를 적을게요. 진행 상태를 어떻게 확인하나요?
- **A** Use the reference number when you contact us.
  - 문의할 때 접수 번호를 사용하세요.
- **B** Great. I'll keep it with my baggage tag receipt.
  - 좋습니다. 수하물표 접수증과 같이 보관할게요.

태그 접수증과 신고 접수 번호는 각각 부친 짐과 이후 신고 내역을 찾는 데 쓰입니다. 어떤 번호를 나중에 말해야 하는지 확인하세요.

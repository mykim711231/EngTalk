# 02. 고객 요청을 요구사항으로 정리하기 (Turning Client Requests into Requirements)

## 학습 목표

- 과 ID · vol9-02
- 핵심 문법 · G11 확인 질문 + G12 수동태로 요구사항과 현재 상태 정리하기
- 상황 검색어 · 모호한 요청, 요구사항, 필수·선택 항목, 우선순위, 인수 기준, 승인 일정
- 말하기 목표 · 모호한 요청을 측정 가능한 요구사항으로 바꾸고, 필수와 선택 항목을 나눈 뒤, 우선순위와 인수 기준(acceptance criteria)을 확인해 승인 일정을 잡습니다.

## 기본 대화

A는 Pinecrest의 비즈니스 분석가 Jisoo이고, B는 Harbor Market 운영 책임자 Daniel입니다. 첫 미팅 기록을 바탕으로 고객의 요청을 요구사항으로 바꾸는 작업 세션입니다.

- **A** Thanks for the notes, Daniel. / I've turned your requests into a first list of requirements, / and I'd like to confirm each one.
  - 메모 감사합니다, 대니얼. 요청 사항을 첫 요구사항 목록으로 정리했고, 하나씩 확인하고 싶습니다.
- **B** Good. / How did you translate "make it simple"?
  - 좋습니다. "간단하게 만들어 달라"는 요청은 어떻게 옮겼나요?
- **A** We wrote it as one clear requirement: / a repeat order is placed in three taps or fewer. / Does that match what you meant?
  - 명확한 요구사항 하나로 적었습니다. 재주문은 세 번 이내의 탭으로 완료됩니다. 의도하신 것과 맞나요?
- **B** Almost. / Three taps is right for a repeat order, / but a new order can take longer.
  - 거의 맞습니다. 재주문은 세 번이 맞지만, 새 주문은 더 걸려도 됩니다.
- **A** Then we'll split them into two requirements. / Right now orders are typed in by hand, / so the store copy is the other must-have. / Would a one-minute confirmation count as fast enough?
  - 그럼 두 개의 요구사항으로 나누겠습니다. 지금은 주문이 직접 입력되고 있으니, 매장 전달본이 또 하나의 필수 항목입니다. 1분 이내 확인이면 충분히 빠른 것으로 볼 수 있을까요?
- **B** Yes. / And the order should appear on the tablet as soon as it's confirmed.
  - 네. 그리고 주문은 확인되는 즉시 태블릿에 나타나야 합니다.
- **A** Understood. / That one goes on the must-have list. / For the brand feel, / custom photos are planned, / but the color work is a nice-to-have. / Is that the right priority?
  - 알겠습니다. 그 항목은 필수 목록에 넣겠습니다. 브랜드 느낌은 맞춤 사진을 계획에 넣고, 색상 작업은 선택 항목으로 두겠습니다. 이 우선순위가 맞나요?
- **B** That's right. / The photos are a must-have, / and the palette can wait for phase two. / A prioritized list by Thursday would help us sign off.
  - 맞습니다. 사진은 필수이고, 색상은 2단계로 미뤄도 됩니다. 목요일까지 우선순위를 표시한 목록을 주시면 승인하는 데 도움이 되겠습니다.

## 문장 구조와 바꿔 말하기

- 대화 문장 · A repeat order is placed in three taps or fewer.
- 문장 구조 · `A repeat order`(주어) + `is placed`(be + 과거분사) + `in three taps or fewer`(기준)
- 뜻과 어순 · G12 수동태는 누가 하는지보다 요구되는 상태와 결과를 앞세웁니다. `A repeat order is placed in three taps or fewer.`는 고객이 재주문을 세 번 이내로 마친다는 결과를 규정하고, `Orders are typed in by hand.`는 현재의 처리 상태를 설명합니다. 요구사항은 이렇게 측정 가능한 상태로 적어야 나중에 완료 여부를 판단할 수 있습니다. G11으로는 `Does that match what you meant?`처럼 상대의 의도를 확인하고, `Could you confirm which items are must-haves?`처럼 목록을 확인합니다.
- 바꿔 말하기 · 기준을 바꿀 때는 `A new order is completed in five steps or fewer.`라고 합니다. 능동문 `We send the confirmation within one minute.`은 G12로 `The confirmation is sent within one minute.`처럼 바꿔 요구사항 문장으로 만들 수 있습니다.

## 주요 단어와 표현

모호한 요청을 요구사항으로 바꾸고 우선순위를 확인할 때 쓰는 표현을 정리합니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### requirement

- 발음 (미국식 IPA) · /rɪˈkwaɪr.mənt/
- 뜻 · 반드시 충족해야 하는 조건
- 예문 · I've turned your requests into a first list of requirements.
- 번역 · 요청 사항을 첫 요구사항 목록으로 정리했습니다.

### must-have

- 발음 (미국식 IPA) · /ˈmʌst.hæv/
- 뜻 · 반드시 포함해야 하는 항목
- 예문 · That one goes on the must-have list.
- 번역 · 그 항목은 필수 목록에 넣겠습니다.

### nice-to-have

- 발음 (미국식 IPA) · /ˌnaɪs tə ˈhæv/
- 뜻 · 있으면 좋지만 없어도 되는 항목
- 예문 · The color work is a nice-to-have.
- 번역 · 색상 작업은 선택 항목입니다.

### acceptance criteria

- 발음 (미국식 IPA) · /əkˈsep.təns kraɪˈtɪr.i.ə/
- 뜻 · 완료 여부를 판단하는 합의된 기준
- 예문 · We agreed on acceptance criteria for each must-have.
- 번역 · 필수 항목마다 인수 기준을 합의했습니다.

### translate

- 발음 (미국식 IPA) · /trænsˈleɪt/
- 뜻 · 말이나 요청을 다른 형태로 옮기다
- 예문 · How did you translate "make it simple"?
- 번역 · "간단하게 만들어 달라"는 요청은 어떻게 옮겼나요?

### repeat order

- 발음 (미국식 IPA) · /rɪˈpiːt ˌɔːr.dɚ/
- 뜻 · 이전과 같은 주문을 다시 하는 것
- 예문 · A repeat order is placed in three taps or fewer.
- 번역 · 재주문은 세 번 이내의 탭으로 완료됩니다.

### confirmation

- 발음 (미국식 IPA) · /ˌkɑːn.fɚˈmeɪ.ʃən/
- 뜻 · 주문이 접수됐다는 확인
- 예문 · Would a one-minute confirmation count as fast enough?
- 번역 · 1분 이내 확인이면 충분히 빠른 것으로 볼 수 있을까요?

### palette

- 발음 (미국식 IPA) · /ˈpæl.ət/
- 뜻 · 디자인에 쓰는 색상 조합
- 예문 · The palette should feel warm, not corporate.
- 번역 · 색상 조합은 기업적이기보다 따뜻하게 느껴져야 합니다.

### sign off

- 발음 (미국식 IPA) · /ˌsaɪn ˈɑːf/
- 뜻 · 검토 후 최종 승인하다
- 예문 · A prioritized list by Thursday would help us sign off.
- 번역 · 목요일까지 우선순위를 표시한 목록을 주시면 승인하는 데 도움이 되겠습니다.

### split

- 발음 (미국식 IPA) · /splɪt/
- 뜻 · 하나를 둘 이상으로 나누다
- 예문 · Then we'll split them into two requirements.
- 번역 · 그럼 두 개의 요구사항으로 나누겠습니다.

### tap

- 발음 (미국식 IPA) · /tæp/
- 뜻 · 화면을 한 번 누르는 동작
- 예문 · Three taps is right for a repeat order.
- 번역 · 재주문은 세 번의 탭이 맞습니다.

### priority

- 발음 (미국식 IPA) · /praɪˈɔːr.ə.t̬i/

- 예문 · Is that the right priority?
- 번역 · 이 우선순위가 맞나요?

### phase two

- 발음 (미국식 IPA) · /ˌfeɪz ˈtuː/
- 뜻 · 두 번째 개발 단계
- 예문 · The color palette can wait for phase two.
- 번역 · 색상 팔레트는 2단계로 미뤄도 됩니다.

## 발음 포인트

`A repeat order is placed in three taps or fewer.`에서 `A repeat order`는 `uh-ri-PEET-or-der`처럼 붙여 말하고, `is placed in`은 `iz-PLAY-din`, `taps or fewer`는 `TAP-sor FYOO-er`처럼 이어 말합니다. `REPEAT`, `PLACED`, `THREE`, `FEW`를 강조해 요구사항의 기준이 무엇인지 분명히 하세요.

## 응용 대화

고객사 IT 책임자가 태블릿의 실시간 연결이 어렵다고 알려 옵니다. A는 Jisoo이고 B는 Daniel입니다. 두 사람은 동기화 주기를 요구사항에 반영하고 인수 기준을 다시 정합니다.

- **A** I spoke with your IT lead this morning. / There's one constraint we need to build into the requirements.
  - 오늘 아침 IT 책임자와 통화했습니다. 요구사항에 반영해야 할 제약이 하나 있습니다.
- **B** What's that?
  - 무엇인가요?
- **A** The tablets can't connect to the store system in real time. / Orders can be synced every ten minutes, / not instantly.
  - 태블릿이 매장 시스템에 실시간으로 연결되지 않습니다. 주문은 즉시가 아니라 10분마다 동기화될 수 있습니다.
- **B** Ten minutes is workable for most stores, / but the busiest one needs faster updates.
  - 대부분 매장은 10분이면 괜찮지만, 가장 바쁜 매장은 더 빠른 갱신이 필요합니다.
- **A** Then let's make the ten-minute sync the baseline, / and list real-time sync for that store as a nice-to-have. / Would that work?
  - 그럼 10분 동기화를 기본으로 하고, 그 매장의 실시간 동기화는 선택 항목으로 두겠습니다. 그렇게 하면 될까요?
- **B** Yes. / The customer still needs the confirmation right away, though.
  - 네. 그래도 고객은 확인 메시지를 바로 받아야 합니다.
- **A** The customer confirmation is sent immediately, / and only the store copy is delayed. / So the must-haves on the customer side don't change. / Shall I update the list tonight?
  - 고객 확인은 즉시 발송되고, 매장 전달본만 지연됩니다. 그래서 고객 쪽 필수 항목은 바뀌지 않습니다. 오늘 밤에 목록을 업데이트할까요?
- **B** Please do. / Send it before Thursday, / so we can review it with IT.
  - 그렇게 해 주세요. 목요일 전에 보내 주시면 IT와 함께 검토하겠습니다.

기술 제약이 생기면 전체 요구사항을 흔들기보다 기본값과 선택 항목을 나눕니다. 고객이 체감하는 부분이 그대로라면 필수 항목은 유지된다는 점을 분명히 말하세요.

## 복습

1. "간단하게"라는 요청이 요구사항으로 바뀐 내용을 고르세요.
   - A. 모든 화면을 한 번의 탭으로 줄입니다.
   - B. 재주문을 세 번 이내의 탭으로 완료합니다.
   - C. 새 주문도 세 번 이내로 제한합니다.
   - D. 주문 단계를 다섯 개로 늘립니다.
2. 현재 주문 처리 상태를 G12로 말해 보세요.
3. 응용 대화에서 10분 동기화가 기본이 된 이유는 무엇인가요?
4. 필수 항목과 선택 항목을 하나씩 골라 말해 보세요.

## 듣고 답하기

### 1. 모호한 요청을 측정 가능한 요구사항으로 바꾸기

- 상대 음성 · We want the app to feel simple and fast.
- 힌트 · 의도를 확인하는 G11 질문을 한 뒤, 재주문 기준을 세 번 이내의 탭으로 제안하세요.
- 예시 답변 · Does that match what you meant? We can write it as a repeat order placed in three taps or fewer.
- 확인 · 상대의 의도를 확인하고 측정 가능한 기준으로 바꿨나요?

### 2. 현재 상태와 인수 기준 확인하기

- 상대 음성 · The order should appear on the tablet right away.
- 힌트 · 그 항목을 필수로 표시하고, 현재는 직접 입력된다는 점과 1분 확인 기준을 확인하세요.
- 예시 답변 · That one goes on the must-have list. Right now orders are typed in by hand, so would a one-minute confirmation count as fast enough?
- 확인 · 필수 표시와 인수 기준을 함께 말했나요?

### 3. 제약이 생겼을 때 우선순위 다시 정하기

- 상대 음성 · The busiest store needs real-time updates.
- 힌트 · 10분 동기화를 기본으로, 실시간 동기화는 선택 항목으로 두고, 고객 확인은 즉시 발송된다고 설명하세요.
- 예시 답변 · Let's make the ten-minute sync the baseline and list real-time sync as a nice-to-have. The customer confirmation is still sent immediately.
- 확인 · 기본값과 선택 항목을 나누고 고객 영향이 없다는 점을 밝혔나요?

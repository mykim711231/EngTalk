# 14. 옷을 입어 보고 핏 설명하기 (Trying On Clothes and Describing the Fit)

## 학습 목표

- 과 ID · vol2-14
- 핵심 문법 · G02 be동사와 too + 형용사로 불편함 설명하기
- 상황 검색어 · 옷 입어 보기, 탈의실, 어깨, 소매, 허리, 너무 크다, 핏
- 말하기 목표 · 탈의실을 묻고, 입어 본 옷의 어느 부분이 잘 맞거나 불편한지 설명합니다.

## 기본 대화

B는 재킷을 사기 전에 탈의실에서 입어 봅니다. 직원 A가 어디가 잘 맞는지 묻습니다.

- **A** Would you like to try it on?
  - 입어 보시겠어요?
- **B** Yes, please. Where's the fitting room?
  - 네. 탈의실은 어디예요?
- **A** It's in the back on the left.
  - 뒤쪽 왼편에 있어요.
- **B** Thanks. I'll be right back.
  - 고맙습니다. 곧 돌아올게요.
- **A** How does it fit?
  - 핏은 어떠세요?
- **B** It fits well in the shoulders, but the sleeves are too long.
  - 어깨는 잘 맞는데 소매가 너무 길어요.
- **A** Would you like to try the short version?
  - 소매가 짧은 버전도 입어 보시겠어요?
- **B** Yes, I'd like to try that.
  - 네, 그것도 입어 보고 싶어요.

  - 이 바지로 할게요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · The sleeves are too long.
- 문장 구조 · `The sleeves`(주어) + `are`(be동사) + `too long`(소매 상태)
- 뜻과 어순 · `too long`은 입는 사람에게 너무 길다는 뜻입니다. 어떤 부분이 문제인지 `the sleeves`나 `the waist`를 말하면 직원이 다른 옷을 찾기 쉽습니다.
- 바꿔 말하기 · 소매가 아니라 허리 쪽이 너무 끼면 `It's too tight around the waist.`라고 말해 보세요.

## 발음 포인트

`too LONG`과 `too TIGHT`를 또렷하게 구분해 보세요. 어떤 부분이 문제인지 `sleeves`나 `waist`까지 포함해 한 문장으로 말합니다.

## 응용 대화

B는 바지 허리가 끼어서 한 단계 큰 사이즈를 입어 보고 비교합니다.

- **A** How do those pants fit?
  - 그 바지는 핏이 어떠세요?
- **B** They're too tight around the waist. Do you have the next size up?
  - 허리 쪽이 너무 껴요. 바로 위 사이즈가 있나요?
- **A** Yes. Here you go.
  - 네. 여기요.
- **B** This pair is more comfortable. The legs are a little loose, though.
  - 이 바지가 더 편해요. 다만 바지통이 조금 넉넉하네요.
- **A** Would you like to try a slimmer cut?
  - 더 슬림한 디자인을 입어 보시겠어요?
- **B** No, thanks. I think I'll go with this pair.
  - 괜찮아요. 이 바지로 할게요.

`How does it fit?`을 들으면 편한 부분이나 불편한 부분을 하나 골라 설명합니다. `too tight`는 불편할 만큼 끼고, `a little loose`는 조금 넉넉하다는 뜻입니다.

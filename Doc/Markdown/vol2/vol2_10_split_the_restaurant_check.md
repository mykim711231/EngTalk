# 10. 계산서를 나눠 달라고 하기 (Asking to Split the Check)

## 학습 목표

- 과 ID · vol2-10
- 핵심 문법 · G04 could로 계산 방식 요청하기
- 상황 검색어 · 계산서 나누기, 따로 계산, 각자 낸 음식, 절반씩, 공용 메뉴
- 말하기 목표 · 각자 주문한 음식을 따로 계산할지 전체 금액을 나눌지 말하고, 함께 먹은 메뉴를 어떻게 계산할지 확인합니다.

## 기본 대화

A는 직원이고 B는 친구와 식사한 손님입니다. 두 사람은 자기 음식은 각자 내고 함께 먹은 메뉴는 반씩 나눕니다.

- **A** Ready for the check?
  - 계산서를 드릴까요?
- **B** Yes, please. Could we get separate checks?
  - 네. 계산서를 따로 주실 수 있을까요?
- **A** Sure. Which items are yours?
  - 네. 어느 메뉴가 손님 것이죠?
- **B** The sandwich and the iced tea are mine.
  - 샌드위치랑 아이스티가 제 거예요.
- **A** And the fries?
  - 감자튀김은요?
- **B** We shared the fries. Could you split those between us?
  - 감자튀김은 같이 먹었어요. 그건 둘이 나눠 계산해 주실래요?
- **A** Sure. I'll put half on each check.
  - 네. 각각의 계산서에 반씩 넣을게요.
- **B** Perfect. Thank you.
  - 좋아요. 감사합니다.

## 핵심 문장

  - 감자튀김은 같이 먹었어요.

  - 어느 메뉴가 손님 것이죠?

## 문장 구조와 바꿔 말하기

- 대화 문장 · Could we get separate checks?
- 문장 구조 · `Could`(조동사) + `we`(주어) + `get`(동사원형) + `separate checks`(원하는 계산서)
- 뜻과 어순 · `separate checks`는 계산서를 사람별로 달라는 말입니다. 전체를 같은 금액으로 나누려면 `split the check evenly`라고 하여 어떤 방식인지 분명히 말합니다.
- 바꿔 말하기 · 서로 다른 계산서 대신 전체를 반씩 나누어 낼 수 있는지 물으세요. `Could we split the check evenly?`

## 발음 포인트

`separate checks`의 `separate`는 여기서 형용사이므로 마지막 부분을 `/ət/`에 가깝게 짧게 말합니다. `split the check EVENLY`에서는 `evenly`를 들려주어 금액을 똑같이 나눈다는 점을 전하세요.

## 응용 대화

식당에서 품목별로 계산서를 분리하기는 어렵지만 두 카드에 나누어 결제할 수 있다고 합니다.

- **A** Here's the check.
  - 여기 계산서입니다.
- **B** Could we get separate checks?
  - 계산서를 따로 받을 수 있을까요?
- **A** I can't separate the items, but we can take two cards.
  - 품목을 나눠 계산하기는 어렵지만 카드 두 장으로 결제할 수 있어요.
- **B** Could you charge half to each card?
  - 각 카드에 반씩 결제해 주실래요?
- **A** Yes, I can split the check evenly.
  - 네, 전체 금액을 똑같이 나눠 결제할 수 있어요.
- **B** Great. That works for us.
  - 좋아요. 저희는 그렇게 하면 돼요.

`split the check`만으로는 품목별인지 같은 금액인지 모호할 수 있습니다. `evenly`나 `half to each card`를 붙여 정확히 어떤 방식인지 말하세요.

# 09. 상대의 성과를 축하하기 (Congratulating Someone on an Achievement)

## 학습 목표

- 과 ID · vol6-09
- 핵심 문법 · G09 because와 so로 성과의 이유와 결과 이어 말하기
- 상황 검색어 · 축하, 승진, 완주, 훈련, 축하 식사, 후속 질문
- 말하기 목표 · 상대의 성과를 진심으로 축하하고, 과정에 대해 묻고, 함께 축하할 자리를 제안합니다.

## 기본 대화

A는 B의 게시물을 보고 하프 마라톤 완주 소식을 알게 된 친구입니다. 두 사람은 만나서 완주 이야기를 나누고, A는 B의 과정을 묻고 축하 식사를 제안합니다.

- **A** I saw your post this morning. / You finished the half marathon!
  - 오늘 아침에 네 게시물 봤어. 하프 마라톤 완주했구나!
- **B** I did. / I'm still sore, / but I'm really happy.
  - 응. 아직 몸이 뻐근한데 정말 기뻐.
- **A** Congratulations. / That's a huge accomplishment.
  - 축하해. 정말 대단한 성과야.
- **B** Thanks. / I've been training since January, / so it feels surreal.
  - 고마워. 일월부터 훈련했더니 아직도 믿기지 않아.
- **A** I can imagine. / How was the course?
  - 그럴 만하네. 코스는 어땠어?
- **B** Hilly for the first few miles, / but the view along the river was worth it.
  - 처음 몇 마일은 언덕이 많았는데 강을 따라가는 경치가 그만한 가치가 있었어.
- **A** That sounds amazing. / Let me buy you brunch this weekend. / You've earned it.
  - 정말 멋졌겠다. 이번 주말에 브런치를 사 줄게. 그럴 자격이 있어.
- **B** I'd love that. / Honestly, / I just want to sit down for a few hours.
  - 정말 좋아. 솔직히 몇 시간은 그냥 앉아 있고 싶어.

## 문장 구조와 바꿔 말하기

- 대화 문장 · I've been training since January, so it feels surreal.
- 문장 구조 · `I`(주어) + `have been training`(계속 이어 온 훈련) + `since January`(시작점) + `so`(그래서) + `it feels surreal`(결과)
- 뜻과 어순 · G09에서 `so`는 앞에 온 이유나 원인을 받아 뒤에 결과를 말합니다. 여기서는 오랫동안 훈련해 온 것이 이유가 되고, 그 결과로 믿기지 않는다고 말합니다. 같은 내용을 `because`로 바꾸면 결과를 먼저 말하고 이유를 뒤에 붙입니다. `since`는 시작점, `for`는 기간과 씁니다.
- 바꿔 말하기 · 결과를 먼저 말하려면 `It feels surreal because I've been training since January.`라고 해 보세요. 기간을 말할 때는 `I've been training for ten months.`처럼 `for`를 씁니다.

## 발음 포인트

`I've been training since January, so it feels surreal.`에서 `I've been`은 `I've-bin`처럼 붙여 말하고, `training since`는 `training-since`로 이어 말합니다. `January`와 `surreal`에 강세를 두고, `so it feels`는 `so-wit-feels`처럼 연결하세요. `surreal`은 두 번째 음절에 강세를 둡니다.

## 응용 대화

A는 B의 승진 소식을 듣고 축하 인사를 전합니다. B는 기쁘면서도 새 팀을 맡는 부담을 이야기하고, A는 그 마음을 인정하며 축하 저녁을 제안합니다.

- **A** I heard the news. / Congratulations on the promotion!
  - 소식 들었어. 승진 축하해!
- **B** Thanks. / It still doesn't feel real.
  - 고마워. 아직도 실감이 안 나.
- **A** You've been leading that project for two years. / You earned it.
  - 그 프로젝트를 이 년 동안 이끌었잖아. 네가 받을 자격이 있어.
- **B** That's kind of you to say. / I'm excited, / but I'm also a little nervous.
  - 그렇게 말해 주니 고맙다. 기대되지만 조금 긴장도 돼.
- **A** That makes sense. / It's a bigger team, right?
  - 그럴 만해. 팀이 더 커지는 거지?
- **B** Yes. / I'll have eight people instead of three, / so I'm going to need to delegate more.
  - 응. 세 명 대신 여덟 명을 맡게 돼서 더 많이 업무를 나눠 맡겨야 할 것 같아.
- **A** You'll figure it out. / How about dinner next week to celebrate? / My treat.
  - 잘 해낼 거야. 다음 주에 저녁 먹으면서 축하할까? 내가 살게.
- **B** That sounds great. / And thanks for not making it weird. / Some people have been a little cold about it.
  - 좋아. 그리고 이상하게 굴지 않아서 고마워. 몇몇은 좀 싸늘하게 대하더라고.

축하할 때는 성과 자체뿐 아니라 그 뒤에 있는 과정을 짚어 주고, 비교나 부러움 대신 함께 기뻐하는 말을 고르면 좋습니다.

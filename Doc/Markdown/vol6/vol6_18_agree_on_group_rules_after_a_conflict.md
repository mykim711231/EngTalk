# 18. 갈등이 생긴 모임의 규칙 합의하기 (Agreeing on Group Rules After a Conflict)

## 학습 목표

- 과 ID · vol6-18
- 핵심 문법 · G09 because로 각자의 불편과 이유를 말하고 규칙으로 잇기
- 상황 검색어 · 룸메이트 갈등, 공용 공간, 설거지, 소음, 규칙 합의
- 말하기 목표 · 갈등 상황에서 내 불편을 이유와 함께 말하고, 몇 가지 규칙을 제안해 모두의 동의를 확인합니다.

## 기본 대화

A와 B는 함께 사는 룸메이트이고, 최근 부엌 청소 문제로 서로 불편을 느꼈습니다. 두 사람은 감정을 탓하지 않고 각자의 이유를 말한 뒤, 규칙 몇 가지를 정해 동의를 구합니다.

- **A** Can we talk about the kitchen for a minute? / I've been a little frustrated.
  - 부엌 이야기 잠깐 할 수 있어? 요즘 좀 불편해서.
- **B** Sure. / I've noticed things pile up too.
  - 그래. 나도 물건이 쌓이는 건 봤어.
- **A** It's not just the dishes. / I get stressed because I can't cook when the sink is full.
  - 설거지만 문제가 아니야. 싱크대가 가득하면 요리를 못 해서 스트레스를 받아.
- **B** I hear you. / My problem is the timing, / because I work late and leave them overnight.
  - 무슨 말인지 알아. 내 문제는 시간이야, 늦게까지 일해서 그릇을 밤새 두게 되거든.
- **A** That makes sense. / So maybe two rules. / Whoever cooks cleans up that night, / and no dishes in the sink by morning.
  - 그럴 만하네. 그럼 규칙 두 개를 정하자. 요리한 사람이 그날 치우기, 아침까지 싱크대에 그릇 남기지 않기.
- **B** I can live with that. / Could we also keep the counters clear? / I need space to prep.
  - 그 정도면 괜찮아. 조리대도 비워 두면 좋겠어. 준비할 공간이 필요하거든.
- **A** Agreed. / And if someone can't clean up, / they text the group by ten.
  - 동의해. 그리고 정말 못 치우는 날에는 열 시까지 단체 채팅에 알리기.
- **B** That works for me. / I'll check with Jae tonight / and confirm with everyone.
  - 나도 좋아. 오늘 밤에 재에게 확인하고 다들한테 알릴게.

## 문장 구조와 바꿔 말하기

- 대화 문장 · I get stressed because I can't cook when the sink is full.
- 문장 구조 · `I`(주어) + `get stressed`(감정 상태) + `because`(이유) + `I can't cook when the sink is full`(이유 절)
- 뜻과 어순 · G09에서 `because` 뒤에는 주어와 동사가 있는 절이 옵니다. 갈등을 말할 때는 상대를 탓하는 문장보다 `I get stressed because ~`처럼 내 상태와 이유를 먼저 말하면 방어적으로 들리지 않습니다. 이유 절 안에 `when`을 넣어 상황을 더 구체적으로 말할 수 있습니다. 해결책은 `so`로 이어 `The sink was full, so I couldn't cook.`처럼 결과를 말합니다.
- 바꿔 말하기 · 아침에 화장실이 붐벼서 불편하다고 말하려면 `I'm frustrated because the bathroom is crowded in the morning.`이라고 해 보세요. 이유를 먼저 말할 때는 `The bathroom is crowded in the morning, so I'm frustrated.`처럼 `so`로 결과를 잇습니다.

## 발음 포인트

`I get stressed because I can't cook when the sink is full.`에서 `get stressed`를 한 덩어리로 말하고 `stressed`에 강세를 두세요. `because I`는 `buh-cuz-eye`로 이어 말하고, `can't`는 `can`과 구분되도록 마지막 `t`를 살짝 내어 또렷하게 말합니다. `sink is full`은 `sin-kiz-full`처럼 연결합니다.

## 응용 대화

이번에는 동네 정원 모임입니다. A와 B는 공동 도구와 물 주기 문제로 갈등이 생겼고, 각자의 불편을 이유와 함께 말한 뒤 규칙 몇 가지를 정합니다. 마지막에는 단체 채팅으로 확인하기로 합니다.

- **A** Thanks for meeting early. / I wanted to sort out the garden tools.
  - 일찍 만나 줘서 고마워. 정원 도구 문제를 정리하고 싶어.
- **B** Good idea. / I've been frustrated too, / because people leave the tools out in the rain.
  - 좋은 생각이야. 나도 좀 불편했어, 사람들이 도구를 비 맞게 내버려 두니까.
- **A** Same here. / And the watering got confusing, / so some beds dried out last week.
  - 나도 그래. 그리고 물 주는 일이 헷갈려서 지난주에 마른 화단이 생겼어.
- **B** So what if we set two rules? / Tools go back in the shed, / and we follow a watering chart.
  - 그럼 규칙 두 개를 정하면 어떨까? 도구는 창고에 넣기, 그리고 물 주기 표를 따르기.
- **A** I like that. / Could we also share the watering duties? / That way no one carries it alone.
  - 좋아. 물 주기 표를 공동 당번으로 하면 어떨까? 한 사람이 혼자 떠안지 않게.
- **B** Yes. / Let's post it in the group chat, / and confirm with everyone by Friday.
  - 응. 단체 채팅에 올리고, 금요일까지 다들 확인받자.
- **A** Works for me. / I'll draft it tonight.
  - 나도 찬성. 오늘 밤에 초안을 만들게.
- **B** Great. / If no one objects, / we'll start Monday.
  - 좋아. 아무도 이의가 없으면 월요일부터 시작하자.

갈등이 생겼을 때는 누가 잘못했는지보다 어떤 상황이 불편한지에 초점을 맞추고, 규칙은 두 개 정도로 좁혀야 지킬 가능성이 높아집니다. 마지막에는 모두가 동의했는지 꼭 확인하세요.

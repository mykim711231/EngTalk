# 13. 상대와 생각이 다를 때 표현하기 (Expressing Disagreement Respectfully)

## 학습 목표

- 과 ID · vol6-13
- 핵심 문법 · G09 because로 걱정의 이유를 붙여 의견 차이 말하기
- 상황 검색어 · 의견 차이, 여행 예산, 절충안, 비용 걱정, 반대 의견
- 말하기 목표 · 상대의 의견에서 타당한 점을 먼저 인정하고, 이유를 붙여 걱정을 말한 뒤, 절충안을 제안합니다.

## 기본 대화

A와 B는 친구 넷이 함께 떠나는 여행을 준비합니다. A는 차를 빌리자고 하고, B는 비용이 걱정됩니다. 두 사람은 서로의 이유를 듣고 일주일 내내가 아니라 이틀만 빌리는 절충안을 찾습니다.

- **A** I still think we should rent a car for the trip.
  - 나는 그래도 여행에 차를 빌려야 한다고 생각해.
- **B** I get why you'd want one. / But I'm worried about the cost, / because the rental plus gas adds up fast.
  - 왜 차가 필요한지는 알아. 그런데 비용이 걱정이야, 렌트비에 기름값까지 하면 금방 많이 늘어나니까.
- **A** That's a fair point. / My concern is time, though. / The trails are far from town, / and the buses run only twice a day.
  - 타당한 지적이야. 그래도 내 걱정은 시간이야. 등산로가 시내에서 멀고, 버스는 하루에 두 번밖에 안 다녀.
- **B** Fair enough. / I didn't realize the schedule was that thin.
  - 그렇구나. 버스가 그렇게 뜸한 줄은 몰랐어.
- **A** So maybe we compromise. / We could rent for two days instead of the whole week.
  - 그래서 절충해 보자. 일주일 내내가 아니라 이틀만 빌릴 수도 있어.
- **B** That could work. / I'd feel better because we'd still have a cap on spending.
  - 그건 괜찮을 것 같아. 지출 상한이 있으니까 마음이 놓여.
- **A** Exactly. / And we can split it four ways, / so it won't hit anyone too hard.
  - 바로 그거야. 그리고 넷이 나눠 내면 아무도 부담이 크지 않아.
- **B** Okay. / I'm still not thrilled about the price, / but I can live with that plan.
  - 좋아. 가격이 마음에 썩 드는 건 아니지만, 그 계획이면 받아들일 수 있어.

## 문장 구조와 바꿔 말하기

- 대화 문장 · I'm worried about the cost because the rental plus gas adds up fast.
- 문장 구조 · `I`(주어) + `'m worried about the cost`(걱정하는 내용) + `because`(이유) + `the rental plus gas adds up fast`(이유 절)
- 뜻과 어순 · G09에서 `because`는 주어와 동사가 있는 절을 붙여 이유를 말합니다. 의견이 다를 때는 상대의 말에서 맞는 부분을 먼저 인정하고, `I'm worried because ~`처럼 자기 걱정의 이유를 말하면 반박이 아니라 설명으로 들립니다. 명사에는 `because of the cost`처럼 `because of`를 씁니다.
- 바꿔 말하기 · 사람이 많은 곳이 부담된다고 이유를 붙이려면 `I'd rather go in the morning because it gets crowded later.`라고 해 보세요. 이유를 먼저 말할 때는 `It gets crowded later, so I'd rather go in the morning.`처럼 `so`로 결과를 잇습니다.

## 발음 포인트

`I'm worried about the cost because the rental plus gas adds up fast.`에서 `worried about`은 `wurry-dabout`처럼 붙여 말하고, `because the`는 `buh-cuz-thuh`로 이어 말합니다. `adds up`은 `ad-zup`처럼 연결하고, `cost`와 `adds up fast`에 강세를 두세요. `My concern is time, though.`에서는 `time`을 또렷하게 강조해 걱정의 초점을 드러냅니다.

## 응용 대화

A와 B는 같은 여행에 친구 지수도 부르자는 이야기를 합니다. A는 함께 가면 좋겠다고 하고, B는 지수의 사정을 먼저 생각하자고 말합니다. 두 사람은 짐작하지 않고 지수에게 직접 묻기로 합니다.

- **A** I was thinking we could invite Jisoo too.
  - 지수도 부르면 어떨까 생각했어.
- **B** I like Jisoo. / I'm just not sure this is the right trip for her.
  - 지수는 좋아. 다만 이번 여행이 지수에게 맞을지 모르겠어.
- **A** Why not? / She's easy to travel with.
  - 왜? 지수는 같이 다니기 편한 사람이잖아.
- **B** She is, / but she's on a tight budget right now, / so I don't want her to feel pressured.
  - 맞아. 그런데 지금 지출이 빠듯해서 부담을 느끼게 하고 싶지 않아.
- **A** That's a good point. / I didn't think about that.
  - 좋은 지적이야. 그건 생각 못 했어.
- **B** Maybe we just ask her honestly. / She can decide for herself.
  - 그냥 솔직하게 물어보는 게 좋겠어. 결정은 지수가 할 수 있잖아.
- **A** Yeah. / I'd rather ask than leave her out. / If she says no, that's fine.
  - 그래. 빼 놓기보다는 물어보는 게 낫지. 싫다고 하면 괜찮고.
- **B** Agreed. / I'm glad we talked it through instead of guessing.
  - 동의해. 짐작만 하지 않고 이야기해서 다행이야.

의견이 다를 때는 "네 말이 틀렸어" 대신 "그 부분은 맞아, 다만 나는 이게 걱정이야"로 시작하면 대화가 방어적으로 흐르지 않습니다.

## 듣고 답하기

### 1. 상대 의견 인정하고 걱정 말하기

- 상대 음성 · I still think we should rent a car for the trip.

- 확인 · 인정과 걱정을 함께 말했나요?

### 2. 내 걱정의 초점을 짚고 정보 더하기

- 상대 음성 · That's a fair point. My concern is time, though. The buses run only twice a day.
- 힌트 · 버스가 하루에 두 번뿐이라는 말을 듣고, 일정이 그렇게 뜸한 줄 몰랐다고 받아 주세요.

- 확인 · 상대의 정보를 듣고 생각이 바뀐 부분을 말했나요?

- 힌트 · 지출 상한이 있어서 마음이 놓인다고 말하고, 계획을 받아들이세요.

- 확인 · 이유를 붙여 절충안을 받아들였나요?

# 14. 우체국에서 택배 보내기 (Sending a Package at the Post Office)

## 학습 목표

- 과 ID · vol3-14
- 핵심 문법 · G06 to와 by로 목적지와 도착 희망 시점 말하기
- 상황 검색어 · 우체국, 소포, 택배 보내기, 주소, 도착 예정, 배송 추적 번호
- 말하기 목표 · 소포를 어디로 보낼지 말하고 배송 속도와 요금을 비교한 뒤 추적 번호를 확인합니다.

## 기본 대화

B는 책을 담은 소포를 국내 다른 도시로 보냅니다. A는 우체국 직원입니다.

- **A** How can I help you?
  - 무엇을 도와드릴까요?
- **B** I'd like to send this package to Denver.
  - 이 소포를 덴버로 보내고 싶어요.
- **A** Okay. Is the address on the package?
  - 알겠습니다. 소포에 주소가 적혀 있나요?
- **B** Yes, here's the shipping label.
  - 네, 여기 배송 라벨이 있어요.
- **A** How soon does it need to arrive?
  - 얼마나 빨리 도착해야 하나요?
- **B** By Friday, if possible. What are my options?
  - 가능하면 금요일까지요. 어떤 방법이 있나요?
- **A** I can show you the delivery estimates and prices.
  - 배송 예상 날짜와 가격을 보여 드릴게요.
- **B** Great. Does this option include tracking?
  - 좋아요. 이 방법에는 배송 추적도 포함되나요?

## 문장 구조와 바꿔 말하기

- 대화 문장 · I'd like to send this package to Denver.
- 문장 구조 · `I`(주어) + `would like`(하고 싶다) + `to send`(보내다) + `this package`(보낼 것) + `to Denver`(보낼 곳)
- 뜻과 어순 · 도시는 `to Denver`, 도착 희망 기한은 `by Friday`라고 합니다. 목적지와 기한을 함께 먼저 알려 주면 배송 옵션을 좁히기 쉽습니다.
- 바꿔 말하기 · 이 소포를 시카고로 보내고 가능하다면 목요일까지 도착하면 좋겠다고 말하세요.

## 발음 포인트

`to DENver`와 `by FRIday`를 듣고 장소와 날짜를 각각 찾아보세요. 배송 추적 번호를 읽을 때는 숫자를 하나씩 또렷하게 말합니다.

## 응용 대화

B에게는 빠른 배송이 필요하지 않습니다. 주소와 배송 추적 번호를 확인합니다.

- **A** The quicker option costs more. Does it need to arrive by Friday?
  - 더 빠른 방법은 비용이 더 들어요. 금요일까지 도착해야 하나요?
- **B** No, next week is fine. I'll take the cheaper option.
  - 아니요, 다음 주에 도착해도 괜찮아요. 더 저렴한 방법으로 할게요.
- **A** Okay. Please check the ZIP Code on the label.
  - 알겠습니다. 라벨에 적힌 우편번호를 확인해 주세요.
- **B** It's correct. Where can I find the tracking number?
  - 맞아요. 배송 추적 번호는 어디에서 찾을 수 있나요?
- **A** The tracking number is on the receipt.
  - 배송 추적 번호는 영수증에 있습니다.
- **B** Great. I'll keep the receipt.
  - 좋습니다. 영수증은 가지고 있을게요.

`What are my options?`로 가능한 배송 방법을 듣고, 예상 날짜와 가격을 함께 비교합니다. 도착일이 중요하다면 실제로 보장되는지 직원에게 확인합니다.

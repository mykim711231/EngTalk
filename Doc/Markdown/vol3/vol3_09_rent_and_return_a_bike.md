# 09. 자전거를 빌리고 반납하기 (Renting and Returning a Bike)

## 학습 목표

- 과 ID · vol3-09
- 핵심 문법 · G06 명령문으로 순서 안내하기
- 상황 검색어 · 자전거 대여, 반납, 거치대, 앱 잠금 해제, 빈 자리
- 말하기 목표 · 자전거를 빌리는 곳과 반납할 수 있는 곳을 물어보고 반납이 완료됐는지 확인합니다.

## 기본 대화

B는 공유 자전거를 처음 이용하며 도움을 주는 직원 A에게 질문합니다.

- **A** Do you need a hand with the bike?
  - 자전거 이용에 도움이 필요하세요?
- **B** Yes. How do I rent a bike?
  - 네. 자전거를 어떻게 빌리나요?
- **A** Open the app and scan the code on the bike.
  - 앱을 열고 자전거에 있는 코드를 스캔하세요.
- **B** When can I take the bike out?
  - 언제 자전거를 빼면 되나요?
- **A** When it unlocks. Wait for the confirmation in the app.
  - 잠금이 풀리면요. 앱 화면에서 확인 메시지를 기다리세요.
- **B** Okay. Can I return it at another station?
  - 알겠습니다. 다른 대여소에 반납할 수 있나요?
- **A** Yes, if there's an open dock.
  - 네, 빈 거치대가 있다면요.
- **B** Great. I'll check the app first.
  - 좋네요. 앱을 먼저 확인할게요.

## 문장 구조와 바꿔 말하기

- 대화 문장 · Open the app and scan the code on the bike.
- 문장 구조 · `Open`(첫 동사원형) + `the app`(열 것) + `and`(이어 주는 말) + `scan`(다음 동사원형) + `the code on the bike`(스캔할 것)
- 뜻과 어순 · 절차를 알려 줄 때는 `Open …`, `Scan …`처럼 동사원형으로 시작합니다. 두 행동을 `and`로 이으면 어떤 순서로 해야 하는지 보여 줄 수 있습니다.
- 바꿔 말하기 · ‘앱을 열고 지도에서 대여소를 확인하세요’를 `Open the app and check the map.`이라고 말하세요.

## 발음 포인트

`RENT a bike`와 `reTURN a bike`의 서로 다른 동사를 듣고 대여와 반납을 구분해 말하세요.

## 응용 대화

B가 반납하려는 곳에 자리가 없어 직원 A에게 빈 거치대가 있는 곳을 물어봅니다.

- **A** Can I help you?
  - 도와드릴까요?
- **B** There isn't an open dock here. Is there another station nearby?
  - 여기 빈 거치대가 없어요. 근처에 다른 대여소가 있나요?
- **A** Yes, the app shows an open dock at the library.
  - 네, 앱에 도서관 대여소에 빈 거치대가 있다고 나와요.
- **B** Thanks. How do I know my ride has ended?
  - 감사합니다. 이용이 끝났는지 어떻게 알 수 있나요?
- **A** Check the dock light and the confirmation in the app.
  - 거치대 표시등과 앱의 확인 메시지를 확인하세요.
- **B** I'll check both when I return it.
  - 반납할 때 둘 다 확인할게요.

`station`은 대여소 전체이고 `dock`은 자전거 한 대가 들어가는 자리입니다. 공유 자전거 서비스마다 반납 표시는 다를 수 있어 안내를 확인합니다.

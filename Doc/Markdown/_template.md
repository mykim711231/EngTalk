# NN. 한국어 제목 (English Title)

## 학습 목표

- 과 ID · volN-NN
- 핵심 문법 · GNN 문법 이름
- 상황 검색어 · 한국어 검색어, 필요한 행동
- 말하기 목표 · 과를 마친 학습자가 실제로 할 수 있는 말이나 행동

## 기본 대화

상황과 화자 A, B의 역할을 설명합니다. 아래처럼 화자와 발화 순서를 표시합니다. 6~8발화로 기본 상황을 마무리합니다.

- **A** English utterance
  - 자연스러운 한국어 번역
- **B** English response
  - 자연스러운 한국어 번역

## 핵심 문장

### 필수 표현

초급에서 먼저 듣고 직접 말할 표현을 3~4개 고릅니다.

- English sentence / optional meaning unit
  - 자연스러운 한국어 번역

### 확장 표현

필수 표현에 더해 문장 전체가 10~12개가 되도록 확장 표현을 작성합니다.

- English sentence
  - 자연스러운 한국어 번역

## 문장 구조와 바꿔 말하기

- 대화 문장 · English sentence
- 문장 구조 · `단어`(주어) + `단어`(동사) + `단어`(목적어 또는 보어)
- 뜻과 어순 · 문장의 뜻과 이 과의 핵심 문법을 짧게 설명
- 바꿔 말하기 · 한 요소를 바꿔 말하도록 한국어 힌트와 영어 예시 제시

## 주요 단어와 표현

본문이나 회화에 나오는 단어와 표현 10~15개에 미국식 IPA, 문맥상 뜻, 예문과 번역을 적습니다. 강세 표시 `ˈ`는 바로 뒤 음절을 강조한다는 뜻입니다.

### English headword

- 발음 (미국식 IPA) · /IPA/
- 뜻 · 이 과에서 쓰인 뜻
- 예문 · English example sentence
- 번역 · 자연스러운 한국어 번역

## 발음 포인트

기본 대화에 나오는 문장 하나에서 뜻을 가르는 강세나 이어 말하기를 짚습니다. 먼저 듣고, 짧게 끊어서 말한 뒤, 전체 문장을 다시 말하게 합니다.

## 응용 대화

기본 상황에서 조건을 하나 바꾸거나 예상 밖의 질문, 실수 또는 문제를 해결합니다. 화자와 역할을 설명하고 6~8발화로 구성합니다.

- **A** English utterance
  - 자연스러운 한국어 번역
- **B** English response
  - 자연스러운 한국어 번역

필요한 경우 상대나 상황에 따른 표현 차이를 한두 문장으로 설명합니다.

## 복습

3~5문제를 작성합니다. 선택 문제의 정답과 영어로 말하는 문제의 예시 답변은 문제 뒤에 둡니다.

1. 듣고 뜻을 확인하는 문제
   - A. 선택지
   - B. 선택지
   - C. 선택지
   - D. 선택지
2. 한국어로 상황을 읽고 영어로 말하는 문제
3. 응용 대화에서 중요한 조건이나 결정을 찾는 문제

정답과 예시 답변을 적습니다.

## 듣고 답하기

### 1. 역할 연습 제목

- 상대 음성 · English speaking prompt
- 힌트 · 학습자가 답할 내용 또는 조건
- 예시 답변 · 가능한 응답 1개 이상
- 확인 · 의사소통 목표를 이루었는지 스스로 확인할 항목

두 번째 연습에서는 상대의 말이나 상황을 바꿉니다. 필요하면 여기에 오늘날 자주 쓰는 채널이나 추가 상황을 확장 연습으로 붙입니다.

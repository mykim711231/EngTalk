# EngTalk — 영어 회화 학습 PWA 설계 초안

문서 상태는 검토안입니다. 첫 교재의 형식과 240과 편성안을 함께 확인합니다.

## 목표와 교재 분량

한국어 사용자가 영어 대화를 듣고, 뜻을 확인하고, 자신의 말로 바꿔 말할 수 있게 합니다. 초급 생활회화부터 여행, 직장, 토론까지 [12권 240과](curriculum.md)로 편성합니다. 권별로 추가할 수 있도록 전체 권 수와 과 수는 교재 목록에서 읽습니다.

| 기본 구성 | 과별 목표 | 240과 환산 |
|---|---:|---:|
| 핵심 문장 | 10~12개 | 2,400~2,880개 |
| 두 상황의 대화 | 대화당 6~8발화 | 480편, 2,880~3,840발화 |
| 단어장 항목 | 10~15개 | 2,400~3,600항목 |
| 복습 문제 | 3~5개 | 720~1,200문제 |

단어장 수치는 과별 등록 건수입니다. 같은 표현을 다시 가르칠 때는 용법, 관계 또는 상황을 바꿉니다. 2편의 대화도 주문과 주문 수정처럼 서로 다른 목표를 둡니다.

## 교재 원본

- 권별로 `Doc/Markdown/volN/`에 Markdown 파일을 한 과씩 둡니다. 권 번호와 과 번호는 파일명에 포함하고, 학습 기록에 사용하는 과 ID는 발행 후 유지합니다.
- 과는 학습 목표, 핵심 문장, 주요 단어와 표현, 발음 포인트, 표현과 문법, 응용 회화, 복습, 말하기 연습 순으로 구성합니다.
- 핵심 문장과 회화는 영어와 한국어를 한 쌍으로 적습니다. 회화에는 화자 이름과 발화 순서를 명시합니다.
- 영어 원문에서 ` / `는 교재 작성자가 표시하는 의미 단위 경계입니다. 전체 문장 음성에는 경계를 제거하고 원래 문장부호를 유지합니다.
- 단어장 항목에는 표제어, 이 과에서 쓰인 뜻, 영어 예문, 한국어 번역을 적습니다. 필요한 경우 문장에 나오는 변형을 조회 형태로 함께 적습니다.
- [01과 카페에서 주문하기](Markdown/vol1/vol1_01_cafe_order.md)를 첫 교재 형식의 기준으로 삼습니다.

## 학습 화면과 단어장

1. **교재**에서 핵심 문장과 A/B 회화를 문장별 또는 순서대로 듣습니다. 영어와 한국어 표시를 각각 제어하고, 영어가 표시될 때 의미 단위 구분을 켤 수 있습니다.
2. **단어장**은 본문과 회화의 영어 단어를 누르면 열립니다. 이 과의 문맥상 뜻, 발음 듣기, 예문과 번역을 보여줍니다. 등록된 표현이 겹치면 해당 위치를 포함하는 가장 긴 표현을 우선합니다. 예를 들어 주문 문장에서 `to`나 `go`를 누르면 `to go`의 뜻인 ‘포장으로’를 보여줍니다. 미등록 단어를 눌렀을 때는 단어와 발음 버튼, 해당 과의 뜻 준비 상태를 표시합니다.
3. **따라 말하기**에서 한 발화씩 기기 음성을 들은 뒤 자기 목소리를 녹음하고 재생합니다. 회화의 화자 순서를 유지합니다.
4. **복습**에서 듣고 뜻을 고르거나 한국어를 보고 영어를 떠올립니다. 완료한 과와 다시 볼 문장을 기기에 저장합니다.

## 배포와 저장

- 첫 구현은 미국 영어(`en-US`) 기기 음성을 사용합니다. 기기에 설치된 영어 음성으로 오프라인 재생이 가능한지 확인합니다.
- 교재 원본은 권별 JSON과 단어장 자료로 변환합니다. 작은 전체 목차로 과를 고르고, 교재는 필요한 권을 저장하는 구조를 검토합니다. 사전 합성 MP3를 추가하면 음원도 권별로 내려받을 수 있게 합니다.
- GitHub Pages에 배포할 때 설치 경로와 서비스 워커 범위는 `/EngTalk/`를 사용합니다. 진도, 설정, 복습, 백업 및 음원 캐시는 EngTalk 식별자로 관리합니다.

## 분량과 저장 용량

로컬 ChinTalk 교재는 160과이며 교재·사전·음원 목록 JSON 12개는 약 2.8MB, MP3 7,034개는 약 109.7MB입니다. 같은 과당 MP3 용량으로 240과를 단순 환산하면 약 164.5MB입니다. 실제 영어 음원은 문장 길이, 음질, 화자 수 및 한국어 음원 포함 여부에 따라 달라집니다. 출시 전 합성 후보 음원으로 과당 용량을 측정하고 권별 다운로드에 반영합니다. [GitHub Pages 배포 용량 제한](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

## 작성과 검수 순서

1. 카페 주문 과 한 편으로 교재 표기, 여러 단어로 된 표현 조회, 전체 회화 재생, 퀴즈, 오프라인 교재 열기와 두 앱 사이 저장 격리를 검증합니다.
2. 1권을 완성하면서 영어의 자연스러움, 문맥에 맞는 한국어 뜻, 과별 중복, 발음 및 회화 화자 순서를 검수합니다.
3. 12권까지 권 단위로 작성합니다. 빈 섹션, 중복 과 ID, 영어·한국어 쌍 누락, 교재에서 한 번도 쓰이지 않은 단어장 표현을 검출할 수 있게 작성 규칙을 유지합니다.

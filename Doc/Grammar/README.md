# EngTalk 문법 목차

회화를 듣고 한 문장을 골라 **누가, 무엇을 하는지, 무엇을 더 말하는지** 확인합니다. 그날 배운 구조로 단어를 바꿔 한 문장을 더 말합니다. 권별 학습 목표와 상황은 [전체 편성표](../curriculum.md)에서 볼 수 있습니다.

## 문장 뼈대부터 시작하기

| 뼈대 | 예문 | 문장 안에서 하는 일 |
|---|---|---|
| 주어 + 동사 | `I work.` | `I`는 일하는 사람, `work`는 하는 일 |
| 주어 + 동사 + 보어 | `I am new.` | `new`는 주어 `I`의 상태를 설명 |
| 주어 + 동사 + 목적어 | `I handle requests.` | `requests`는 `handle`의 대상 |

회화에서 질문하면 어순이 달라집니다. `Could I get a latte?`에서는 **조동사 `Could` + 주어 `I` + 동사원형 `get` + 목적어 `a latte`**입니다. 먼저 문장 전체를 듣고 `a latte`만 `an iced tea`로 바꿔 말해 보세요. [조동사 의문문](https://dictionary.cambridge.org/us/grammar/british-grammar/could) · [카페 주문 1과](../Markdown/vol1/vol1_01_cafe_order.md)

## 1~3권 · 생활 영어

| ID | 문법 | 바꿔 말하기 |
|---|---|---|
| G01 | 주어·동사·목적어·보어 | `I work.` → `I work with Mina.` · `I handle calls.` |
| G02 | be동사와 축약형, be동사 질문 | `I'm Mina.` → `I'm Daniel.` · `Are you Daniel?` |
| G03 | 일반동사 현재형, do/does 질문과 부정 | `I work on Fridays.` → `Do you work on Fridays?` · `I don't work on Fridays.` |
| G04 | 조동사로 정중하게 요청하기 | `Could I get a latte?` → `Could I get an iced tea?` |
| G05 | 관사, 복수형, 수량과 가격 | `a sandwich` → `two sandwiches` · `How much are they?` |
| G06 | 명령문과 위치·방향 표현 | `Turn left at the light.` → `Turn right at the light.` |

G02는 [이름 묻기](../Markdown/vol1/vol1_02_ask_names.md), G04는 [카페 주문](../Markdown/vol1/vol1_01_cafe_order.md)에서 연습합니다. `Could I get …?`는 첫 과에서 주문에 바로 쓰고, 이후 길을 묻거나 요청할 때 G04를 다시 확인합니다.

## 4~6권 · 여행과 상황 대처

| ID | 문법 | 바꿔 말하기 |
|---|---|---|
| G07 | 과거형과 did 질문 | `I booked a room.` → `Did you book a room?` · `I booked it yesterday.` |
| G08 | will, be going to, 현재진행형으로 미래 말하기 | `I'll call the hotel now.`로 지금 할 일을 말합니다. `I'm going to call the hotel tonight.`로 계획을, `I'm staying at a hotel next week.`로 정해진 숙박 일정을 말합니다. |
| G09 | 이유와 조건 연결 | `I need a new room because the heater isn't working.` · `If a room opens up, could you call me?` |

## 7~9권 · 직장과 비즈니스

| ID | 문법 | 바꿔 말하기 |
|---|---|---|
| G10 | 진행 중인 일, 끝난 일, 현재 결과 | 현재 상황에 맞춰 `We're testing it now.`, `We finished testing yesterday.`, `We've finished testing.`로 보고합니다. |
| G11 | 간접 질문과 확인 | `When is it due?` → `Could you tell me when it's due?` |
| G12 | 수동태로 상태와 처리 결과 설명 | `We approved the change.` → `The change was approved.` |
| G13 | 조건과 합의 내용 | `If the scope changes, we'll need more time for testing.`에서 조건이나 결과를 바꿉니다. |

[첫 출근 인사](../Markdown/vol7/vol7_01_first_day_intro.md)에서는 G01을 다시 씁니다. 생활 대화에서 익힌 `I + 동사 + 대상`으로 `I handle support requests.`처럼 자신의 담당 업무를 설명합니다.

## 10~12권 · 토론과 고급 말하기

| ID | 문법 | 바꿔 말하기 |
|---|---|---|
| G14 | 전달과 간접화법 | `The timing is tight.` → `She said the timing was tight.` |
| G15 | 양보와 대조 | `Although the option costs more, it's easier to maintain.`에서 상대가 인정할 장점과 제약을 바꿉니다. |
| G16 | 가정과 대안 | `If we had more time, we could test both options.`에서 제약과 대안을 바꿉니다. |
| G17 | 근거와 결론 연결 | `Given the feedback, I recommend keeping the current plan.`에서 근거와 제안을 바꿉니다. |

## 복습에서 확인하는 것

문장 성분을 표시하고, 문장의 일부를 바꾸고, 상대가 물었을 때 자기 상황에 맞춰 답합니다. 학습자에게는 문법 용어와 함께 실제로 말할 수 있는 예문을 보여줍니다. 문법을 다시 배울 때는 처음 접한 과와 다른 권에서 다시 쓰는 과를 함께 표시합니다.
